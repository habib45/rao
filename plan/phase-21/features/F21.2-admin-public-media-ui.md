Server component that calls `requireAdmin()` and renders `AdminShell` wrapping `PublicMediaClient`.

---

## `PublicMediaClient` (client component)

Single client component at `src/app/admin/public-media/PublicMediaClient.tsx`.

### State

| State | Type | Purpose |
|---|---|---|
| `items` | `MediaItem[]` | Files + folders from current directory |
| `currentFolder` | `string` | Current path inside `uploads/` (e.g. `"banners"`) |
| `loading` | `boolean` | Fetch in flight |
| `uploading` | `boolean` | Upload in flight |
| `error` | `string \| null` | Error message |
| `copiedPath` | `string \| null` | Path of the last copied item (for feedback) |
| `showCreateFolder` | `boolean` | Controls create-folder modal |
| `newFolderName` | `string` | Controlled input for new folder name |

### Features

**Breadcrumb navigation**
- Shows `uploads / banners / 2026` path parts as clickable links.
- Clicking a part navigates up to that folder.

**Folder navigation**
- Clicking a folder card sets `currentFolder` and re-fetches.

**File upload**
- Hidden `<input type="file" multiple accept="image/*">` triggered by a labelled button.
- On change: POSTs each file as `FormData` to `/admin/api/public-media/upload` with `folder` field.
- Shows "Uploading…" text during upload; re-fetches grid on success.

**Create folder**
- Modal with a text input (validates `^[a-zA-Z0-9_-]+$`).
- POSTs `{ folderName }` to `/admin/api/public-media?folder=<currentFolder>`.

**Copy URL**
- Copies `/uploads/<path>` to clipboard.
- Shows green "Copied!" state for 2 s.

**Delete file**
- `window.confirm` → DELETEs `/admin/api/public-media?path=<item.path>`.

### Card anatomy

**Folder card:**
- Large `<Folder>` icon centered.
- Folder name (truncated).
- Click → navigate into folder.

**Image card:**
- `next/image` thumbnail (`fill`, `object-cover`, container `h-48`).
- File name (truncated) + size formatted (KB / MB).
- [Copy URL] button with Check icon feedback.
- [Delete] icon button (destructive red on hover).

### Styling

Identical to existing `MediaManagerClient` — uses CSS vars (`--color-brand`, `--color-surface`, `--color-border`, `--color-muted`), `rounded-3xl` cards, `shadow-sm`.

### Accessibility

- Upload label has `aria-label="Upload images to public folder"`.
- Every icon button has an `aria-label`.
- Create-folder dialog traps focus via `autoFocus` on the input.
