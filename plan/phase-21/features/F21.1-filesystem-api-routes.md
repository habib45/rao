# F21.1 — File System API Routes

All routes live under `src/app/admin/api/public-media/` and require admin.  
Files are stored in `public/uploads/` relative to the project root.  
Public URL: `/uploads/<relative-path>`.

---

## `GET /admin/api/public-media?folder=<subfolder>`

Lists files and sub-folders at `public/uploads/<folder>` (default: root `""`).

**Response:**
```ts
{
  items: Array<{
    name: string;
    path: string;       // relative path inside uploads/ (e.g. "banners/hero.jpg")
    publicUrl: string;  // "/uploads/banners/hero.jpg"
    size: number | null;
    isFolder: boolean;
    updatedAt: string | null;
  }>
}
```

**Implementation notes:**
- Uses `fs.readdirSync` with `{ withFileTypes: true }`.
- Filters out `.gitkeep` files from the listing.
- Returns folders first, then image files.
- Image files: extensions `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.svg`.

---

## `POST /admin/api/public-media?folder=<subfolder>`

Creates a new sub-folder inside `public/uploads/<folder>`.

**Body (JSON):**
```ts
{ folderName: string }  // validated: ^[a-zA-Z0-9_-]+$, 1–64 chars
```

**Implementation:**
- Creates `public/uploads/<folder>/<folderName>/` with `fs.mkdirSync({ recursive: true })`.
- Writes a `.gitkeep` placeholder inside the new folder.
- Returns `{ path: "<folder>/<folderName>" }`.

---

## `DELETE /admin/api/public-media?path=<relative-path>`

Deletes a single file at `public/uploads/<path>`.

**Validation:**
- `path` must not be empty, must not start with `/`, must not contain `..`.
- File must be an image (by extension).

**Implementation:**
- Uses `fs.unlinkSync`.
- Returns `{ ok: true }`.

---

## `POST /admin/api/public-media/upload`

Accepts `multipart/form-data` with one or more files.

**FormData fields:**
- `file` (one or more `File` entries)
- `folder` (string, default `""`) — sub-folder within `uploads/`

**Validation:**
- MIME type must start with `image/`.
- File size must be ≤ 10 MB (returns 413 otherwise).
- File name: sanitised (spaces → underscores, strip non-word chars except `.`, `-`).

**Implementation:**
- Reads `file.arrayBuffer()` and writes via `fs.writeFileSync`.
- Creates the target directory if it does not exist.
- Returns `{ ok: true, paths: string[] }` with the public URLs of uploaded files.

---

## Security Rules (all routes)

1. `requireAdmin()` called first — unauthenticated/non-admin → 401/403.
2. `path` and `folder` params are sanitised: no `..`, no absolute paths.
3. Resolved absolute path must start with `process.cwd() + "/public/uploads"` (prefix check prevents escaping).
4. File extension whitelist: `.jpg .jpeg .png .webp .gif .svg`.
