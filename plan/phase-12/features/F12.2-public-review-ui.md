# F12.2 — Public Review UI

## Component: `ReviewSection` (client)

Location: `src/app/[locale]/products/[slug]/_components/ReviewSection.tsx`.

### Responsibilities
1. Fetch approved + own pending reviews for the current product via `GET /api/reviews/[productId]`.
2. Render a star-rating summary and a list of reviews (stars, title, body, author first name, date).
3. Render a "Write a Review" form that POSTs to `/api/reviews`.
4. After a successful submission, show a success message and optimistically prepend the pending review to the list.

### Props
```ts
interface ReviewSectionProps {

}
```

### Star Rating Component
Two visual modes:
- Read-only: SVG stars filled by `rating`.
- Interactive: button per star, keyboard accessible (`aria-label="Rate 3 stars"`).

### Date Formatting
Use `Intl.DateTimeFormat` with the `next-intl` locale converted to BCP-47 (`en-US`, `bn-BD`, `sv-SE`).

### Author Display
Only show the first name (everything before the first space). If no space, show the full name.

### Success State
After POST 201 response, show toast-like inline banner: "Your review is pending approval." The returned pending review is prepended to the list with a "Pending approval" badge (amber pill using `--color-brand`).

### Error Handling
- 400 → inline field errors.
- 500/502 → inline banner "Failed to submit review, please try again."

## API Route: `GET /api/reviews/[productId]`

`src/app/api/reviews/[productId]/route.ts`

```ts
export async function GET(
  req: NextRequest,
  { params }: { params: Promise<{ productId: string }> }
) {
  const { productId } = await params;
  const cookieEmail = (await cookies()).get('reviewer_email')?.value ?? null;
  const supabase = createAdminClient(); // service role; bypasses RLS to read own-pending

  let query = supabase
    .from('product_reviews')
    .select('*')
    .eq('product_id', productId)
    .order('created_at', { ascending: false });

  // Either approved OR owned by cookie email
  if (cookieEmail) {
    query = query.or(`status.eq.approved,author_email.eq.${cookieEmail}`);
  } else {
    query = query.eq('status', 'approved');
  }

  const { data, error } = await query;
  if (error) return NextResponse.json({ error: error.message }, { status: 500 });
  return NextResponse.json({ reviews: data });
}
```

## API Route: `POST /api/reviews`

`src/app/api/reviews/route.ts`

```ts
export async function POST(req: NextRequest) {
  const body = await req.json();
  const parsed = reviewCreateSchema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json(
      { error: 'Validation failed', issues: parsed.error.issues },
      { status: 400 }
    );
  }

  const supabase = createAdminClient();
  const { data, error } = await supabase
    .from('product_reviews')
    .insert({ ...parsed.data, status: 'pending' })
    .select()
    .single();

  if (error) return NextResponse.json({ error: error.message }, { status: 500 });

  const res = NextResponse.json({ review: data }, { status: 201 });
  res.cookies.set('reviewer_email', parsed.data.author_email, {
    maxAge: 60 * 60 * 24 * 365,
    path: '/',
    sameSite: 'lax',
    httpOnly: false,
  });
  return res;
}
```

## Integration in Product Detail Page
`src/app/[locale]/products/[slug]/page.tsx` imports `ReviewSection` (client) and embeds it below the existing product info block. Product ID is passed in from the server fetch.

## Accessibility
- Form uses semantic `<label>` + `<input>` pairs.
- Star rating exposes `role="radiogroup"` with each star as `role="radio"`.
- Submission status is announced via an `aria-live="polite"` region.
