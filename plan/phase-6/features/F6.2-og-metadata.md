# F6.2 — OG / Twitter Card Metadata

## Description

Every page exports `generateMetadata` returning full Open Graph and Twitter card tags. Uses locale-aware title and description from the product's `TranslationMap`.

## Product Detail Page Metadata

```ts
export async function generateMetadata({ params }) {
  const product = await getProduct(params.slug, params.locale);
  return {
    title: `${product.name[locale]} | BestFinds`,
    description: product.meta_description?.[locale] ?? product.description?.[locale]?.slice(0, 155),
    openGraph: {
      title: product.name[locale],
      description: ...,
      images: [{ url: primaryImage.url, width: 800, height: 800 }],
      type: "website",
      locale: params.locale,
    },
    twitter: {
      card: "summary_large_image",
      title: product.name[locale],
      images: [primaryImage.url],
    },
  };
}
```

## Acceptance Criteria

- [ ] `og:title`, `og:description`, `og:image` present on product pages
- [ ] `twitter:card` set to `summary_large_image` on product pages
- [ ] `og:locale` matches current locale
- [ ] Missing product → returns minimal fallback metadata (not error)
- [ ] Description truncated to 155 chars when longer
