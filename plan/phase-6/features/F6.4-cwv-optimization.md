# F6.4 — Core Web Vitals Optimization

## Targets

| Metric | Target | Measurement |
|---|---|---|
| LCP | < 2.5s | Largest Contentful Paint |
| FID/INP | < 100ms | Interaction to Next Paint |
| CLS | < 0.1 | Cumulative Layout Shift |
| FCP | < 1.8s | First Contentful Paint |

## Optimizations

### Images
- All `<Image>` components have explicit `width` and `height` (prevents CLS)
- Primary product image on detail page uses `priority` prop (LCP)
- `sizes` attribute set on grid images for responsive srcset

### Fonts
- Bengali font (`Noto_Sans_Bengali`) loaded via `next/font/google` with `display: "swap"`
- Loaded only in `/bn-BD` locale layout (not global)
- Latin font subset only for en/sv

### ISR & Caching
- `revalidate = 3600` on all product/category pages
- `revalidate = 86400` on sitemap
- `stale-while-revalidate` behavior via ISR

### Bundle Size
- No large client-side libraries on server pages
- Cart logic only in `CartProvider` (client boundary)
- Charts only in admin (not public pages)

### Skeleton States
- `loading.tsx` exports skeleton matching the page layout
- Prevents layout shift on navigation

## Acceptance Criteria

- [ ] Lighthouse Performance ≥ 90 on product detail page (mobile)
- [ ] No `<img>` tags without explicit dimensions
- [ ] No render-blocking scripts
- [ ] Font display swap configured
- [ ] ISR revalidation confirmed via `x-nextjs-cache: STALE` header
