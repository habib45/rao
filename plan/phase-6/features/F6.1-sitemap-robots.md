# F6.1 — robots.txt & Dynamic Sitemap

## robots.ts

```ts
export default function robots(): MetadataRoute.Robots {
  return {
    rules: { userAgent: "*", allow: "/" },
    sitemap: `${process.env.NEXT_PUBLIC_SITE_URL}/sitemap.xml`,
  };
}
```

## sitemap.ts

Generates entries for:
- Homepage: `/en`, `/bn-BD`, `/sv`
- Product pages: all active products × 3 locales (slug from `slug.en`)
- Category pages: all active categories × 3 locales

Each entry includes:
- `url` — canonical URL
- `lastModified` — from `updated_at`
- `changeFrequency` — products: "weekly", homepage: "daily"
- `priority` — homepage: 1.0, products: 0.8, categories: 0.6

## Hreflang Alternates

Each page's `generateMetadata` returns:
```ts
alternates: {
  canonical: `/${locale}/products/${slug}`,
  languages: {
    en: `/en/products/${slug}`,
    "bn-BD": `/bn-BD/products/${slug}`,
    sv: `/sv/products/${slug}`,
    "x-default": `/en/products/${slug}`,
  }
}
```

## Acceptance Criteria

- [ ] `/robots.txt` accessible and contains `Sitemap:` directive
- [ ] `/sitemap.xml` validates against sitemap XSD
- [ ] All active products appear in sitemap
- [ ] All 3 locale variants appear per product
- [ ] `revalidate = 86400` (daily) on sitemap
