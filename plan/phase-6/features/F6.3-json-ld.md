# F6.3 — JSON-LD Structured Data

## Product Page JSON-LD

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Product Name",
  "image": ["https://images-na.ssl-images-amazon.com/..."],
  "description": "...",
  "brand": { "@type": "Brand", "name": "Dell" },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.5",
    "reviewCount": "1234"
  },
  "offers": {
    "@type": "Offer",
    "priceCurrency": "USD",
    "price": "299.99",
    "availability": "https://schema.org/InStock",
    "url": "https://amazon.com/dp/ASIN?tag=..."
  }
}
```

## Homepage JSON-LD

```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "BestFinds",
  "url": "https://yourdomain.com",
  "potentialAction": {
    "@type": "SearchAction",
    "target": "https://yourdomain.com/en/search?q={search_term_string}",
    "query-input": "required name=search_term_string"
  }
}
```

## Acceptance Criteria

- [ ] Product JSON-LD present in `<script type="application/ld+json">` tag
- [ ] Price formatted as decimal string (not integer cents)
- [ ] `availability` maps to correct schema.org URL
- [ ] Rating/reviewCount omitted when null
- [ ] WebSite JSON-LD on homepage
