# F2.4 — Triggers & Functions

## Description

Create PostgreSQL functions and triggers for automatic timestamp management and search vector updates.

## Functions

### set_updated_at()
```sql
CREATE OR REPLACE FUNCTION set_updated_at()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = now();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

### update_product_search_vectors()
Updates tsvector columns when product name/description/brand changes.
```sql
CREATE OR REPLACE FUNCTION update_product_search_vectors()
RETURNS TRIGGER AS $$
BEGIN
  NEW.search_vector_en = to_tsvector('english',
    coalesce(NEW.name->>'en', '') || ' ' ||
    coalesce(NEW.description->>'en', '') || ' ' ||
    coalesce(NEW.brand, ''));
  NEW.search_vector_bn = to_tsvector('simple',
    coalesce(NEW.name->>'bn-BD', '') || ' ' ||
    coalesce(NEW.description->>'bn-BD', ''));
  NEW.search_vector_sv = to_tsvector('simple',
    coalesce(NEW.name->>'sv', '') || ' ' ||
    coalesce(NEW.description->>'sv', ''));
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

## Triggers

| Trigger | Table | Event | Function |
|---|---|---|---|
| trg_categories_updated_at | categories | BEFORE UPDATE | set_updated_at() |
| trg_products_updated_at | products | BEFORE UPDATE | set_updated_at() |
| trg_cart_items_updated_at | cart_items | BEFORE UPDATE | set_updated_at() |
| trg_translations_ui_updated_at | translations_ui | BEFORE UPDATE | set_updated_at() |
| trg_products_search_vectors | products | BEFORE INSERT OR UPDATE | update_product_search_vectors() |
