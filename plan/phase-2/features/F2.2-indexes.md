# F2.2 — Indexes (GIN, tsvector, B-tree)

## Description

Create database indexes for query performance. GIN indexes on all JSONB columns for locale-specific lookups. GiST/GIN indexes on tsvector columns for full-text search. B-tree indexes on frequently queried columns.

## Indexes

### GIN Indexes (JSONB)
| Table | Column | Index Name |
|---|---|---|
| categories | name | idx_categories_name_gin |
| categories | slug | idx_categories_slug_gin |
| products | name | idx_products_name_gin |
| products | slug | idx_products_slug_gin |
| products | description | idx_products_description_gin |
| product_images | alt_text | idx_product_images_alt_text_gin |
| translations_ui | translations | idx_translations_ui_translations_gin |

### GIN Indexes (tsvector — Full-Text Search)
| Table | Column | Index Name |
|---|---|---|
| products | search_vector_en | idx_products_search_en |
| products | search_vector_bn | idx_products_search_bn |
| products | search_vector_sv | idx_products_search_sv |

### B-tree Indexes
| Table | Column(s) | Index Name | Purpose |
|---|---|---|---|
| products | category_id | idx_products_category_id | Category listing queries |
| products | is_active, is_featured | idx_products_active_featured | Homepage featured query |
| products | brand | idx_products_brand | Brand filter |
| product_images | product_id, sort_order | idx_product_images_product_sort | Image ordering |
| click_tracking | product_id, clicked_at | idx_clicks_product_date | Analytics queries |
| click_tracking | session_id | idx_clicks_session | Dedup queries |
| cart_items | session_id | idx_cart_items_session | Cart lookup |
| price_history | product_id, recorded_at | idx_price_history_product_date | Price trend queries |
| categories | parent_id | idx_categories_parent | Tree traversal |
| categories | is_active, sort_order | idx_categories_active_sort | Active category listing |

## Acceptance Criteria

- [ ] All JSONB columns have GIN indexes
- [ ] All 3 tsvector columns have GIN indexes
- [ ] B-tree indexes cover all FK columns and common query patterns
- [ ] Index names follow consistent naming convention
