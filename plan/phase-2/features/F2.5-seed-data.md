# F2.5 — Seed Data

## Description

Insert realistic development/testing data into all tables. Seed data covers all 3 locales and exercises edge cases (null prices, missing translations, featured products, inactive items).

## Seed Counts

| Table | Rows | Notes |
|---|---|---|
| categories | 4 | 3 active + 1 inactive; 1 with parent_id |
| products | 6 | Mix of featured, inactive, null price, all availability states |
| product_images | 8 | Multiple per product, one primary each |
| click_tracking | 3 | Different locales |
| cart_items | 2 | Different sessions |
| price_history | 4 | Multiple entries for same product |
| translations_ui | 3 | Sample UI strings |

## Data Requirements

- All TranslationMap columns must have at least `en` key populated
- At least 1 product with all 3 locale translations
- At least 1 product with bn-BD translation
- At least 1 product with null price_cents
- At least 1 product with availability = 'out_of_stock'
- At least 1 inactive product (is_active = false)
- At least 1 featured product (is_featured = true)
- At least 1 category with parent_id set

## Acceptance Criteria

- [ ] All 7 tables have seed data
- [ ] Seed data respects all constraints and foreign keys
- [ ] Seed data covers all 3 locales
- [ ] Edge cases covered (null prices, inactive items, etc.)
- [ ] Seed SQL is idempotent (uses ON CONFLICT or IF NOT EXISTS)
