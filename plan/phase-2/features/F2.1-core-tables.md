# F2.1 — Core Tables Migration

## Description

## Edge Cases

| Case | Expected |
|---|---|
| Duplicate ASIN | UNIQUE constraint prevents insert |
| Negative price_cents | Allowed (represents credit/adjustment) |
| Rating > 5 or < 0 | CHECK constraint rejects |
| Delete category with products | Products keep category_id=NULL (SET NULL) |
| Delete product with images | Images cascade delete |
| Quantity <= 0 in cart | CHECK constraint rejects |

## Acceptance Criteria

- [ ] All 7 tables created with correct column types
- [ ] All foreign keys defined with appropriate ON DELETE behavior
- [ ] CHECK constraints on rating, availability, locale, quantity
- [ ] UNIQUE constraints on asin, (session_id, product_id), (namespace, key)
- [ ] All JSONB columns default to '{}' or '[]'
- [ ] All timestamps default to now()
