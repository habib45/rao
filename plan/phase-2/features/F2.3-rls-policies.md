# F2.3 — Row Level Security Policies

## Description

Enable RLS on all tables and create policies. This is a public-facing affiliate site — most data is read-only for anonymous users. Write access is restricted to service_role (Edge Functions / admin).

## Policy Matrix

| Table | SELECT (anon) | INSERT (anon) | UPDATE (anon) | DELETE (anon) |
|---|---|---|---|---|
| categories | YES (is_active=true) | NO | NO | NO |
| products | YES (is_active=true) | NO | NO | NO |
| product_images | YES (via product join) | NO | NO | NO |
| click_tracking | NO | YES (insert own) | NO | NO |
| cart_items | YES (own session) | YES (own session) | YES (own session) | YES (own session) |
| price_history | YES | NO | NO | NO |
| translations_ui | YES | NO | NO | NO |

Note: service_role bypasses RLS entirely, so Edge Functions can perform all operations.

## Policies

### categories
- `categories_select_active`: SELECT WHERE is_active = true

### products
- `products_select_active`: SELECT WHERE is_active = true

### product_images
- `product_images_select_all`: SELECT (all rows — images only exist for valid products)

### click_tracking
- `clicks_insert_own`: INSERT WITH CHECK (true) — anyone can track a click

### cart_items
- `cart_select_own`: SELECT WHERE session_id = current_setting('request.headers')::json->>'x-session-id'
- `cart_insert_own`: INSERT WITH CHECK (session_id = current_setting('request.headers')::json->>'x-session-id')
- `cart_update_own`: UPDATE USING (session_id = ...) WITH CHECK (session_id = ...)
- `cart_delete_own`: DELETE USING (session_id = ...)

### price_history
- `price_history_select_all`: SELECT (all rows — public data)

### translations_ui
- `translations_select_all`: SELECT (all rows — public data)

## Acceptance Criteria

- [ ] RLS enabled on all 7 tables (`ALTER TABLE ... ENABLE ROW LEVEL SECURITY`)
- [ ] Anonymous users can only read active categories/products
- [ ] Anonymous users can insert click events
- [ ] Cart operations scoped to session_id
- [ ] No anonymous write access to products, categories, images, price_history, translations_ui
