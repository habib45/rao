# F11.4.4 — AI Rewrite & Translate (Modal Extension)

## Goal
Extend the existing AIAssistantModal so admins can rewrite, simplify, or translate the product description without leaving the editor.

## Surface — `src/app/admin/_components/AIAssistantModal.tsx`
Add four new actions to the `ACTIONS` enum, alongside `generate | improve | seo | persuasive`:

```ts
type Action = 'generate' | 'improve' | 'seo' | 'persuasive' | 'rewrite' | 'simplify' | 'translate';
```

UI:

| Action | Tone Selector | Output Length |
|---|---|---|
| `rewrite` | locked to "professional" | preserve original length ±10% |
| `simplify` | locked to "casual" | shorter (≤ 80% of original) |
| `translate` | locked | preserve length; copy radio for target locale (en, bn-BD, sv); default to "next missing locale" detected from the title map |

The button strip in the modal grows horizontally and wraps. Existing actions remain in place.

## Contract — `POST /admin/api/ai/generate-description`
Body extensions:

```ts
mode: z.enum(['generate','improve','seo','persuasive','rewrite','simplify','grammar','translate'])
  .default('generate'),
targetLocale: z.enum(['en','bn-BD','sv']).optional(),
```

Response is unchanged (HTML string).

## Provider Selection
Reuse the existing provider fallback (`groq` → `gemini` → `openai`). For `simplify` and `translate`, the system prompt is **explicit per-mode**:

| Mode | System prompt fragment |
|---|---|
| `rewrite` | "Rewrite for clarity. Preserve technical accuracy. Keep markdown/HTML structure (h1-h3, ul/ol, tables, links, images, wizard blocks). Return HTML." |
| `simplify` | "Shorten by ~20%. Replace jargon. Keep headings, links, and block IDs intact. Return HTML." |
| `translate` | "Translate the HTML to {{targetLocale}}. Preserve all HTML tags, attribute order, and block IDs. Do not translate URLs, image alt text, or code blocks. Return HTML." |

The translate prompt is the only place that mentions a magic `{{targetLocale}}` placeholder — it is server-replaced before send to avoid the model hallucinating template syntax.

## i18n Preservation
For `translate` and `rewrite`, the route reads the existing `description[targetLocale]` (if any) and inserts it as additional context. The model is told to **preserve wizard/comparison blocks** and not to alter `<table>` content where product specs live.

## Rate Limits
Existing `ai-generate-description` bucket stays. We observe it for the first 7 days; if `rewrite`/`simplify`/`translate` start starving `improve`, we add a second bucket `ai-description-extended` with half capacity (5) sharing the same refill. Phase 11.4 ships *one* bucket and the second is a follow-up if metrics warrant.

## Acceptance
- Each new action returns coherent HTML the editor accepts without sanitization errors.
- Translating en → bn-BD produces Bengali copy that still renders all headings, lists, and tables correctly.
- Wizard/comparison blocks (data-wizard=…, data-comparison=…) round-trip through the modal unchanged.
- Calling `simplify` twice doesn't shrink length below 50% of original (model is told to "shorten by ~20%" twice; on the second call it shortens the already-short text by ~20% more, hitting a soft floor; we surface a toast when output is < 50% of input).

## Tests
- Unit: prompt-builder function returns correct strings for each mode.
- Component: clicking each action renders the result in the editor; HTML is set on the description field.

## Rollback
- The four new actions are gated on `FEATURE_AI_REWRITE=true` (default true for admins).
- Removing the actions from the modal registry hides the UI without touching the route.
