# F11.2 — Rich Text Editor (TipTap)

## Goal
Provide a polished, locale-aware rich text editor for product descriptions that outputs clean HTML storable in JSONB.

## Library Choice
TipTap v2 on ProseMirror. Matches React 19, has SSR safety (via `next/dynamic`), and ships a modular extension set that covers every requested feature.

## Installed Packages
```
@tiptap/react @tiptap/pm @tiptap/starter-kit
@tiptap/extension-table @tiptap/extension-table-row @tiptap/extension-table-header @tiptap/extension-table-cell
@tiptap/extension-image @tiptap/extension-link @tiptap/extension-text-align
@tiptap/extension-underline @tiptap/extension-color @tiptap/extension-text-style
@tiptap/extension-highlight @tiptap/extension-placeholder
```

## Component Contract (`src/app/admin/_components/ui/RichTextEditor.tsx`)

```tsx
"use client";
interface RichTextEditorProps {
  value: string;                // HTML
  onChange: (html: string) => void;
  placeholder?: string;
  className?: string;
}
```

Internal behaviour:
- `useEditor` with StarterKit + the extensions above (StarterKit already includes some, so disable where duplicated).
- `immediatelyRender: false` to stay SSR-safe in the admin layout.
- `onUpdate` pushes `editor.getHTML()` to `onChange`.
- `content` is set from `value` on mount; external changes use `editor.commands.setContent(value, false)` guarded by value-diff comparison.

## Toolbar Layout

Single horizontal toolbar, separated by `|`:

```
Bold · Italic · Underline · Strike  |  H1 · H2 · H3  |  • List · 1. List  |  Table  |  Link · Image URL  |  Align L · C · R  |  Color · Highlight  |  Undo · Redo
```

Each button:
- `type="button"` (prevents accidental form submit).
- `aria-label` describing the action.
- `aria-pressed={editor.isActive(...)}` for toggles.
- `disabled={!editor.can().run(...)}` for undo/redo/insert actions.
- `cn()` styles: active state uses `--color-brand` background tint.

Link and Image buttons open small inline prompts via `window.prompt` in the v1 of this component. (A nicer `Dialog`-based picker is a future enhancement / reused in the Phase 13 Media Manager.)

## Output Format
- HTML string, e.g. `<h2>…</h2><p>…</p>`.
- Stored in `products.description[locale]` alongside any plain-text legacy content.
- Rendered on the public product page using `dangerouslySetInnerHTML` **after sanitisation**. (Sanitisation helper lives outside the scope of this phase; for now we trust admin-authored content, which is stored via service-role routes.)

## SSR / Dynamic Import
```ts
const RichTextEditor = dynamic(
  () => import("@/app/admin/_components/ui/RichTextEditor").then(m => m.RichTextEditor),
  { ssr: false, loading: () => <div className="h-64 animate-pulse rounded-lg bg-surface" /> }
);
```

The editor is always embedded inside a client component wrapper, so direct consumers of `ProductCreateForm` / `ProductEditForm` only pay for the dynamic import within those `"use client"` trees.

## Accessibility
- Full keyboard support inherited from ProseMirror.
- Toolbar buttons expose `aria-label` and `aria-pressed`.
- Editor wrapper has `role="textbox"` implicitly via contenteditable.
- Placeholder is set via `@tiptap/extension-placeholder`.

## Edge Cases
- Empty value: mount with empty string; `isEmpty` detection skips rendering if both `<p></p>` and `""` are treated as empty.
- `value` prop changes from outside (e.g. locale switch): reset editor content without losing cursor if content is identical.
- Paste: StarterKit strips dangerous tags; image paste is disabled (users upload via media manager in Phase 13).
