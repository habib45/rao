# F11.3 — Product Creation Form

## Goal
Let admins create a new product from scratch (or autofill from Amazon) with full locale coverage, and submit it into the Phase 11.1 workflow as either a `draft` or `pending_review`.

## Pages & Components
- `src/app/admin/products/new/page.tsx` — thin server wrapper that requires admin and renders the client form plus a category list fetched via `createAdminClient`.
- `src/app/admin/products/new/_components/ProductCreateForm.tsx` — `"use client"` React Hook Form–style form (but hand-rolled with `useState` to avoid adding RHF).

## Layout

```
┌────────────────────────────────────────────────────────────┐
│ Sync from Amazon                                           │
│  ASIN [          ] [ Sync ]   (autofill from PA-API)       │
├────────────────────────────────────────────────────────────┤
│ Tabs: General | English | Bangla | Swedish | Features |    │
│        Pricing | Images | SEO                              │
├────────────────────────────────────────────────────────────┤
│ <active tab content>                                       │
├────────────────────────────────────────────────────────────┤
│                             [ Save as Draft ]              │
│                             [ Submit for Review ]          │
└────────────────────────────────────────────────────────────┘
```

## Fields

### General
- Category (select, from fetched list).
- Brand (text).
- Availability (select: in_stock / out_of_stock / unknown).
- Affiliate URL (text, filled from import or manual).

### Per-locale (English / Bangla / Swedish)
- Title (text, required for English).
- Slug (text, auto-filled from title via `slugify` if empty).
- Description (RichTextEditor — HTML).
- meta_title (text).
- meta_description (textarea).

### Features
- Dynamic list of plain strings. "+ Add feature" button appends; trash icon removes.

### Pricing
- Currency (default "USD").
- Price cents (input as major units × 100).
- Original price cents (optional).
- Discount % (0–100). Recomputed from price vs original price, editable for override.

### Images
- List of image URL inputs. First = primary. Future enhancement: Phase 13 "Browse Media" button replaces the plain input.

### SEO
- Shown metadata title/description in a preview panel (Google-style), computed from the English tab values.

## Sync from Amazon
- POST `/admin/api/products/import` with `{ asin }`.
- On 201, merge the returned product row into form state (title, description, brand, price, images, affiliate_url, availability).
- On validation error, show inline error next to ASIN input.
- On 502 (PA-API failure), show a toast via `sonner`.

## Submit Behaviour

Both buttons POST to a new `/admin/api/products` route (or reuse if one exists). The payload is the regular product body plus one of:
- `{ product_status: 'draft' }` → "Save as Draft".
- `{ product_status: 'pending_review', submitted_by: <admin email> }` → "Submit for Review".

On success → `router.push(`/admin/products/${id}`)`.
On Zod failure → field-level errors rendered inline.

## Slug Auto-Generation
- When the English title changes and the English slug field is empty or was last auto-filled, re-run `slugify(title)` and set it.
- User can still override manually.

## Accessibility
- Every input has a `<label>`.
- Tab group uses `role="tablist"` / `role="tab"` / `role="tabpanel"` via the existing `Tabs` primitive.
- Buttons disable themselves while the submit is pending.

## Integration With Existing Products Page
`/admin/products` gains a **New Product** button in the top-right of the page header linking to `/admin/products/new`. Icon: `lucide-react` `Plus`.

## Edge Cases
- Duplicate ASIN: `upsert` on the import route means a second sync updates the existing row. The form should then navigate away rather than trying to create duplicates; instead, when an import returns an existing product, we show a toast "Existing product updated" and link to `/admin/products/<id>`.
- Empty features list is allowed.
- Price without original price: discount % defaults to 0.
- Description HTML is trimmed before submit; empty paragraphs `<p></p>` are replaced with `""`.
