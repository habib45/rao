# F5.2 — CartProvider (React Context)

## Description

Global cart state management using React Context. Wraps the app in `[locale]/layout.tsx`. Exposes `useCart()` hook for child components.

## Context API

```ts
interface CartContextValue {
  items: CartItem[];
  itemCount: number;
  totalCents: number;
  addItem(product: Product): void;
  removeItem(productId: string): void;
  updateQuantity(productId: string, qty: number): void;
  clearCart(): void;
}

export function CartProvider({ children }: { children: ReactNode })
export function useCart(): CartContextValue
```

## Implementation Notes

- Initializes from `loadCart()` on mount (client-only via `useEffect`)
- Every mutation calls `saveCart()` after state update
- `itemCount = items.reduce((acc, i) => acc + i.quantity, 0)`
- `totalCents = items.reduce((acc, i) => acc + (i.price_cents ?? 0) * i.quantity, 0)`

## Acceptance Criteria

- [ ] `useCart()` throws if used outside CartProvider
- [ ] `itemCount` updates immediately after `addItem`
- [ ] Cart is populated from localStorage on client mount (no SSR mismatch)
- [ ] `clearCart()` resets items to []
