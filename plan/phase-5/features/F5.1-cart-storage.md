# F5.1 — Cart Storage (localStorage)

## Description

SSR-safe localStorage helpers for reading and writing cart items. Guards all `window` access so server rendering never throws.

## API

```ts
type CartItem = {
  productId: string;
  asin: string;
  name: string;          // en locale name
  price_cents: number | null;
  currency: string;
  image_url: string | null;
  quantity: number;
};

const CART_KEY = "orh_cart";

loadCart(): CartItem[]
saveCart(items: CartItem[]): void
addItem(item: Omit<CartItem, "quantity">): CartItem[]
removeItem(productId: string): CartItem[]
updateQuantity(productId: string, qty: number): CartItem[]
clearCart(): void
```

## Edge Cases

| Case | Expected |
|---|---|
| localStorage unavailable (SSR / private mode) | Returns [] silently, write is no-op |
| Corrupted JSON in localStorage | Returns [], overwrites with [] |
| Quantity updated to 0 | Item removed from array |
| Same product added twice | quantity incremented, not duplicated |

## Acceptance Criteria

- [ ] `addItem` increments quantity for duplicate productId
- [ ] `updateQuantity(id, 0)` removes the item
- [ ] `loadCart()` returns [] during SSR (no window error)
- [ ] `saveCart` is never called during SSR
