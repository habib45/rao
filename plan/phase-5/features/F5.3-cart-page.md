# F5.3 — Cart Page

## Description

Client-rendered cart page at `/[locale]/cart`. Displays all cart items, allows quantity changes, and provides individual "View on Amazon" affiliate links per item (not a unified checkout).

## Sections

1. **Cart items list** — image, name, price, quantity stepper (+/-), remove button
2. **Order summary** — subtotal, item count, disclaimer: "Prices may vary. Complete purchase on Amazon."
3. **"Continue Shopping"** button → `/[locale]/products`
4. **Empty cart state** — illustration + "Your cart is empty" + CTA to browse
5. **Per-item "Buy on Amazon"** button → calls track-click then opens affiliate URL

## No unified checkout
Per Amazon Associates TOS, there is no checkout step. Each item has its own Amazon link.

## Acceptance Criteria

- [ ] Quantity stepper: min 1, max 99
- [ ] Remove button removes item immediately
- [ ] Empty state shown when items.length === 0
- [ ] Subtotal recalculates on quantity change
- [ ] Page is "use client" (cart reads from localStorage)
