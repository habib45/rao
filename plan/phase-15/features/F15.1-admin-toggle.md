# F15.1 — Admin Toggle UI + SettingsForm Update

## Goal
Add a styled Toggle switch component and a "Display Settings" section to the existing admin Settings page so admins can enable/disable site-wide price display.

## Files
| Action | Path |
|---|---|
| Create | `src/app/admin/_components/ui/toggle.tsx` |
| Modify | `src/app/admin/settings/_components/SettingsForm.tsx` |

## Toggle Component
- Hand-built (no Radix/shadcn) — consistent with other admin UI primitives.
- Props: `checked: boolean`, `onChange: (checked: boolean) => void`, `id?: string`, `disabled?: boolean`.
- Pill shape: 44 × 24 px, brand-color when on, muted when off. Animated thumb slide via Tailwind `transition-transform`.

## SettingsForm Changes
- Add `show_price` to the `FeatureFlags` interface (default `true`).
- Add a new "Display Settings" `<Card>` above Feature Flags.
- The card contains one row: **Show Product Prices** with descriptive copy and the `<Toggle>` component.
- Save button calls `saveMutation.mutate({ features })` — same mutation, no API changes needed.
