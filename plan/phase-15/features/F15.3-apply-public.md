# F15.3 — Apply Setting to All Public Price Displays

## Goal
All price-showing components on the public storefront respect `showPrice` from site settings.

## Files
| Action | Path |
|---|---|
| Modify | `src/components/ProductCard.tsx` |
| Modify | `src/app/[locale]/page.tsx` |
| Modify | `src/app/[locale]/products/page.tsx` |
| Modify | `src/app/[locale]/products/[slug]/page.tsx` |

## ProductCard
- Add optional prop `showPrice?: boolean` (default `true`).
- Wrap the entire price `<div>` (lines 65–85) in `{showPrice !== false && ( ... )}`.
- Also hide the discount badge (`-X%`) when `showPrice` is false — price percentage is price data.

## Server Pages
Each of the three pages calls `await getSiteSettings()` and destructures `showPrice`, then passes it to every `<ProductCard ... showPrice={showPrice} />`.

For the product detail page, the price block (current price + original price + "Price unavailable" fallback) is wrapped in `{showPrice && ( ... )}`.
