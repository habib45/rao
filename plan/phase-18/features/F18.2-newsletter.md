# F18.2 — Newsletter Subscription System

## Goal
Allow blog visitors to subscribe to a newsletter and give admins full control over the section's visibility/content and the subscriber list.

## Database

### `newsletter_subscribers` table
```sql
id             uuid PK default gen_random_uuid()
email          text NOT NULL UNIQUE
locale         text NOT NULL default 'en'
name           text
is_active      boolean NOT NULL default true
subscribed_at  timestamptz NOT NULL default now()
unsubscribed_at timestamptz
ip_hash        text  -- sha256 of IP for dedup
```
RLS: public INSERT only (anon can subscribe); service role full access.

### `admin_settings` seeds
Key `newsletter_settings` (JSONB):
```json
{
  "show": true,
  "title": "Subscribe to our newsletter",
  "subtitle": "Sign up to receive our latest news and products. Stay updated on the latest developments and special offers!",
  "background": "indigo"
}
```

## Public API

### `POST /api/newsletter/subscribe`
Body: `{ email: string, locale?: string, name?: string }`  
- Zod validate email format  
- Upsert (on conflict email do update `is_active=true, unsubscribed_at=null`)  
- Return `{ success: true }` or `{ error: "..." }`  
- Rate-limited by IP (max 3 attempts per 10 min via simple count check)

## Public UI — Newsletter Section on Blog Page

Rendered below the post grid, above the footer.  
Reads `newsletter_settings` from `admin_settings` server-side (ISR-safe).  
If `show=false` → renders `null`.

Fields:
- Heading (from settings)
- Subtitle (from settings)
- Email input + Subscribe button (client component `<NewsletterForm>`)
- "I agree to my email being stored" checkbox (required)
- Success toast / error message

## Admin Panel

### `/admin/newsletter` page — 2 tabs

**Tab 1: Settings**
- Show/hide toggle (checkbox)
- Title text input
- Subtitle textarea
- Background color select (indigo / gray / dark)
- Save button → `PATCH /admin/api/newsletter/settings`

**Tab 2: Subscribers**
- Paginated table: email, name, locale, subscribed_at, status (active/unsubscribed)
- Search by email
- Deactivate toggle per row
- CSV export link

### API Routes
- `GET /admin/api/newsletter/settings` — returns `admin_settings` row for key `newsletter_settings`
- `PATCH /admin/api/newsletter/settings` — updates that row; Zod-validated
- `GET /admin/api/newsletter/subscribers?page&perPage&q` — paginated list
- `PATCH /admin/api/newsletter/subscribers/[id]` — toggle `is_active`
