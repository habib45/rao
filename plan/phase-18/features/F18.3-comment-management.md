# F18.3 — Admin Blog Comment Management

## Goal
Give admins a dedicated page to moderate all blog comments: approve, hide (set is_approved=false), and delete them.

## Existing Schema
`blog_comments` already has:
- `id`, `blog_post_id`, `author_name`, `author_email`, `body`, `is_approved`, `parent_id`, `created_at`

No migration needed.

## API Routes

### `GET /admin/api/blog/comments`
Query params: `status=pending|approved|all`, `postId=<uuid>`, `page=1`, `perPage=20`  
Returns: `{ data: BlogComment[], total: number }`  
Joins `blog_posts(title)` for post context.

### `PATCH /admin/api/blog/comments/[id]`
Body: `{ is_approved: boolean }` (Zod validated)  
Updates the row; returns updated comment.

### `DELETE /admin/api/blog/comments/[id]`
Hard delete. Returns `{ success: true }`.

## Admin UI

### `/admin/blog/comments` page
- Filter row: Status tabs (Pending | Approved | All) + Post search select
- Table columns: Post Title | Author | Comment excerpt (100 chars) | Date | Status badge | Actions
- Actions per row:
  - **Approve** button (green check) — sets `is_approved=true`
  - **Hide** button (eye-off icon) — sets `is_approved=false`
  - **Delete** button (trash icon) with confirm dialog
- Pagination (20 per page default)
- Pending count badge shown in AdminShell sidebar next to "Comments"

### AdminShell sidebar additions
- Under Blog section: add "Comments" link pointing to `/admin/blog/comments`
- Add "Newsletter" link pointing to `/admin/newsletter`
