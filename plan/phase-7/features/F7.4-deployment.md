# F7.4 — Production Deployment

## Vercel

- Framework: Next.js (auto-detected)
- Node.js version: 20.x LTS
- Build command: `npm run build`
- Output directory: `.next`
- ISR revalidation: enabled (default with App Router)
- Custom domain: configured via Vercel dashboard

## Vercel Environment Variables

```
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
NEXT_PUBLIC_SITE_URL
SUPABASE_SERVICE_ROLE_KEY
```

## Supabase

- Project on Supabase cloud (non-local)
- Migrations applied: `supabase db push`
- Edge Functions deployed: `supabase functions deploy --all`
- Cron jobs registered in `supabase/config.toml`
- Vault secrets set via Supabase dashboard:
  - `AMAZON_ACCESS_KEY`
  - `AMAZON_SECRET_KEY`
  - `AMAZON_PARTNER_TAG`

## Pre-Launch Checklist

- [ ] All 5 migrations applied to production DB
- [ ] Seed data imported (categories + initial products)
- [ ] PA-API credentials validated (test call returns items)
- [ ] `sync-amazon-products` function triggers successfully
- [ ] `/en`, `/bn-BD`, `/sv` all load without errors
- [ ] Cart persists across page refreshes in production
- [ ] `/admin/login` redirects unauthenticated users
- [ ] Admin user created in Supabase Auth with `app_metadata.role = "admin"`
- [ ] SSL active, no mixed content warnings
- [ ] Affiliate disclosure visible in footer

## Acceptance Criteria

- [ ] Production URL responds with HTTP 200
- [ ] ISR working (second request shows `x-nextjs-cache: STALE`)
- [ ] Edge Functions responding to test requests
- [ ] Admin panel accessible at `/admin`
