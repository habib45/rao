# F7.2 — Security Audit

## Checks

### Secret Exposure
- `grep -r "AMAZON_ACCESS_KEY\|AMAZON_SECRET_KEY\|service_role" src/` → 0 results
- No `NEXT_PUBLIC_` prefix on any secret variable

### SQL Injection
- All Supabase queries use parameterized client (no raw SQL with user input)

- No `dangerouslySetInnerHTML` on user-supplied content
- All translated strings rendered via React (escaped automatically)

### Authentication
- All `/admin/*` routes protected by middleware JWT check
- Service role key only used server-side in API routes after middleware auth

### Amazon TOS Compliance
- Prices refreshed at least once per 24 hours
- No checkout step — all purchases on Amazon
- Affiliate disclosure visible on all pages

### Dependency Audit
- `npm audit --audit-level=high` → 0 high/critical vulnerabilities
