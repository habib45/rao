# F20.5 — Comparison Wizard UI

## Entry point
`src/app/[locale]/products/[slug]/page.tsx` — server fetches:
- `candidates`: up to 10 related products with `show_in_comparison = true`
- `comparisonKeys`: string[] from admin_settings
- Both passed as props to `<ComparisonWizard />`

## ComparisonWizard.tsx (client)
Container: manages `step` (1 | 2 | 3), reads `useComparison()` context.
Current product is always pinned as first column; cannot be deselected.

### Step 1 — Select products
- Header: "Compare with similar items"
- Row of product cards (horizontal scroll on mobile):
  - Current product card: "Viewing this item" badge, greyed +Add
  - Candidate cards: image, truncated title, price, stars, "+ Add" / "✓ Added" button
- Footer: `{count}/6 selected` · "Compare →" (disabled if only 1 selected)

### Step 2 — Comparison table
- Sticky first column = attribute labels
- Product columns: image thumbnail, short name, price
- Fixed rows: Brand · Price · Rating · Availability
- Dynamic rows: each key from `comparisonKeys`, value from `product.attributes[key] ?? "—"`
- Footer: "← Back" · "Add to cart →"

### Step 3 — Cart actions
- Grid of selected products: image, name, price, `<AddToCartButton />`
- Footer: "← Back to comparison" · "Done"

## Styling
Matches existing product detail page — uses `bg-surface`, `border-border`, `text-brand`, Tailwind v4.
