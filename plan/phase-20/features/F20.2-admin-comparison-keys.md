# F20.2 — Admin Comparison Keys Editor

## Location
Admin → Settings page → new "Comparison Keys" card

## Behaviour
- Renders current keys as pills/chips
- Add key: text input + "Add" button (trim, deduplicate, max 20 keys)
- Remove key: × on each pill
- Reorder: drag handle or ↑↓ buttons
- Save: PATCH `/admin/api/settings` with `{ comparison: { keys: [...] } }`
- Optimistic UI via TanStack Query mutation + sonner toast

## Component
`src/app/admin/settings/_components/ComparisonKeysEditor.tsx`
Props: `keys: string[]`, `onChange: (keys: string[]) => void`
