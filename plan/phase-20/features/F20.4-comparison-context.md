# F20.4 — Comparison Context

## File
`src/lib/comparison/index.ts`

## localStorage key
`bf_comparison`

## Shape stored
`string[]` — array of product IDs (max 5, excludes current product which is always pinned)

## Context value
```ts
interface ComparisonContextValue {
  selectedIds: string[];
  add: (id: string) => void;
  remove: (id: string) => void;
  clear: () => void;
  isSelected: (id: string) => boolean;
  canAdd: boolean; // selectedIds.length < 5
}
```

## Provider
`ComparisonProvider` wraps `[locale]/layout.tsx` so state persists across product navigations.
