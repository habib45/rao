# F16.3 — Related Products Section (Product Detail Page)

## Goal
Render a "You may also like" section below the main product layout on the product detail page, using the new `getRelatedProducts()` query and the existing `ProductCard` component.

## Current State
`src/app/[locale]/products/[slug]/page.tsx` ends after the two-column product layout. No related section exists. The `ProductCard` component (`src/components/ProductCard.tsx`) accepts `{ product, locale, showPrice? }`.

## Implementation

### Data fetching
In `ProductPage`, extend the existing `Promise.all` to include `getRelatedProducts`:

```ts
const [product, { showPrice }] = await Promise.all([...]);
// After product guard:
const related = await getRelatedProducts(product.id, product.category_id, 4);
```

Or add as a separate `await` after the null guard — either is fine.

### Import
```ts
import { getProductBySlug, getRelatedProducts } from "@/lib/queries/products";
import ProductCard from "@/components/ProductCard";
```

`ProductCard` is already a default export from `@/components/ProductCard`.

### Section placement
Add **below** the closing `</div>` of the main `max-w-7xl` container, still inside the `<>` fragment:

```tsx
{related.length > 0 && (
  <div className="mx-auto max-w-7xl px-4 sm:px-6 lg:px-8 py-12 border-t border-border">
    <h2 className="text-xl font-bold text-foreground mb-6">
      You may also like
    </h2>
    <div className="grid grid-cols-2 gap-4 sm:grid-cols-3 lg:grid-cols-4">
      {related.map((p) => (
        <ProductCard
          key={p.id}
          product={p}
          locale={loc}
          showPrice={showPrice}
        />
      ))}
    </div>
  </div>
)}
```

### `generateStaticParams`
The product detail page does not currently have `generateStaticParams`. This is pre-existing; no change required for this feature.

## Acceptance Criteria
- Section visible when `related.length > 0`
- Section hidden when no related products exist for the category
- Uses existing `ProductCard` component (no new card component)
- `showPrice` forwarded from `getSiteSettings()` — respects admin toggle
- Section is server-rendered (no `"use client"` added)
- `getRelatedProducts` import added correctly
