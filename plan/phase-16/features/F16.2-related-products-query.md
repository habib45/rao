# F16.2 — `getRelatedProducts()` Query Helper

## Goal
Add a `getRelatedProducts()` function to `src/lib/queries/products.ts` that returns active products from the same category, excluding the current product.

## Why a new function
`getProductsByCategoryLimit(categoryId, limit)` already exists but does **not** exclude the current product. A related-products query must exclude the product being viewed to avoid showing the same item in the "related" list.

## Implementation

### File
`src/lib/queries/products.ts`

### Function signature
```ts
export async function getRelatedProducts(
  productId: string,
  categoryId: string | null,
  limit = 4,
): Promise<Product[]>
```

### Logic
1. If `categoryId` is null → return `[]` immediately (no category to match against)
2. Query `products` table:
   - `.select("*, product_images(*)")`
   - `.eq("is_active", true)`
   - `.eq("category_id", categoryId)`
   - `.neq("id", productId)` ← excludes current product
   - `.order("created_at", { ascending: false })`
   - `.limit(limit)`
3. Return `(data ?? []) as unknown as Product[]`
4. On error: `console.error("getRelatedProducts error:", error.message)` and return `[]`

## Acceptance Criteria
- Returns empty array when `categoryId` is null
- Returns empty array on Supabase error (no throw)
- Excludes the product with `productId` from results
- Returns at most `limit` products, ordered by newest first
- Typescript: no `any`, return type is `Promise<Product[]>`
