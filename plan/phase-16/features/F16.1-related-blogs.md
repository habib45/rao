# F16.1 — Related Blog Posts Section (Blog Detail Page)

## Goal
Render a "More from [Category]" section at the bottom of the blog detail page, below the comments section, using the already-available `getRelatedBlogPosts()` query.

## Current State
- `getRelatedBlogPosts(postId, categoryId, limit)` **already exists** in `src/lib/queries/blog.ts`
- Blog detail page **already calls** `getRelatedBlogPosts(post.id, post.blog_category_id, 4)` and renders results in the **right sidebar** as compact `SidebarPostCard` items
- The user wants a **second, larger display** of related posts as a full-width grid **below the article** (after comments), with richer cards showing cover image, title, category badge, date, and read time

## Implementation

### Location in page
`src/app/[locale]/blog/[slug]/page.tsx` — add a new section after the `</article>` closing tag and before the closing `</div>` of the two-column layout wrapper. Place it **outside** the two-column flex container so it spans full width.

### Section structure
```tsx
{related.length > 0 && (
  <section className="mt-16 border-t border-border pt-10">
    <h2>More from {categoryName ?? "the blog"}</h2>
    <div className="grid gap-6 sm:grid-cols-2 lg:grid-cols-3">
      {related.slice(0, 3).map((p) => (
        <RelatedBlogCard key={p.id} post={p} locale={loc} />
      ))}
    </div>
  </section>
)}
```

### `RelatedBlogCard` component
A new inline component (defined in the same file) rendering:
- Cover image (aspect-video, `next/image` with `fill`)
- Category badge (colored pill, same as `CategoryBadge`)
- Title (localized, line-clamp-2, links to `/blog/[slug]`)
- Published date + read time row

### Data
Reuses the `related` array already fetched via `getRelatedBlogPosts`. No new fetch needed. Limit to 3 cards (slice first 3 from the fetched 4 — sidebar uses all 4).

## Acceptance Criteria
- Section visible when `related.length > 0`
- Section hidden (not rendered) when no related posts
- Section heading uses localized category name when available, fallback "the blog"
- Cards link to correct locale slug
- Cover images use `next/image` (no raw `<img>`)
- Section renders below comments, full width (outside the two-column flex)
