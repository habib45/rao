# F3.2 — sync-amazon-products Edge Function

## Description

Cron-triggered Edge Function (Sundays 3 AM UTC) that fetches all active ASINs from the database, calls PA-API `GetItems`, and upserts product data and images back into Supabase.

## Business Logic

- Reads all rows from `products` where `is_active = true`.
- Batches ASINs into groups of 10; calls `getItems()` for each batch.
- Upserts product fields (name, description, price, availability, images) using `ON CONFLICT (asin)`.
- After 3 consecutive sync failures for an ASIN, sets `is_active = false`.
- Writes a `sync_logs` row on completion (status: success/partial/error).

## Trigger

```toml
# supabase/config.toml
[functions.sync-amazon-products]
schedule = "0 3 * * 0"  # Sundays 03:00 UTC
```

## Acceptance Criteria

- [ ] Processes all active ASINs in batches of 10
- [ ] Upserts product rows without overwriting manually-set fields (brand, category_id)
- [ ] Writes sync_logs row with correct item counts
- [ ] Sets is_active=false after 3 failed lookups
