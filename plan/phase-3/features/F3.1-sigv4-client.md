# F3.1 — AWS SigV4 Signing & PA-API Client

## Description

Implement the AWS Signature Version 4 request-signing algorithm and a typed PA-API 5.0 HTTP client. This shared module is used by all PA-API Edge Functions.

## Business Logic

- PA-API requires every request to be signed with AWS credentials using SigV4 (HMAC-SHA256).
- The signing algorithm: canonical request → string to sign → derived signing key → Authorization header.
- Requests go to `https://webservices.amazon.com/paapi5/getitems` (and `searchitems`).
- Batch size: up to 10 ASINs per `GetItems` call to respect PA-API limits.
- Rate limiting: minimum 1.1s between calls; 429 triggers exponential backoff (max 5 retries).

## Key Functions

### `sigv4.ts`
```ts
signRequest(method, host, path, payload, credentials): Headers
// Returns headers with Authorization, x-amz-date, x-amz-content-sha256
```

### `client.ts`
```ts
getItems(asins: string[]): Promise<PAAPIItem[]>
searchItems(keywords: string, locale: LocaleCode): Promise<PAAPIItem[]>
```

### `transformers.ts`
```ts
transformItem(raw: PAAPIItem): Partial<Product>
transformImage(raw: PAAPIImage): Omit<ProductImage, 'id' | 'product_id'>
```

## Edge Cases

| Case | Expected Behavior |
|---|---|
| ASIN not found on Amazon | Item omitted from response; no DB error |
| PA-API returns 429 | Exponential backoff: 2s, 4s, 8s, 16s, 32s; log and give up after 5 retries |
| Price missing from response | `price_cents: null`; do not overwrite existing DB price |
| Image URL changes | Upsert on `(product_id, sort_order)` to replace old URL |
| Clock skew > 15min | AWS rejects signature; Edge Function must use UTC time |
