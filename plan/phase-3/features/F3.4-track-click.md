# F3.4 — track-click Edge Function

## Description

POST endpoint called from the Next.js affiliate redirect page. Records an affiliate click event to `click_tracking` with deduplication to prevent click fraud.

## Business Logic

- Accepts: `{ product_id, locale, session_id }` in POST body.
- Hashes `ip + user-agent` → `ip_hash` for deduplication.
- Dedup window: if same `(product_id, ip_hash)` within 1 hour, skip insert.
- Returns: `{ ok: true, affiliate_url: string }` — the Amazon Associates URL.

## Acceptance Criteria

- [ ] Inserts click_tracking row on first click
- [ ] Skips insert if same product + ip_hash within 1 hour
- [ ] Returns correct affiliate URL with partner tag
- [ ] Returns 400 if product_id missing or not found
