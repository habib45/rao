# F3.3 — update-prices Edge Function

## Description

Daily cron (1 AM UTC) that refreshes prices for all active products and records price history when the price changes.

## Business Logic

- Batches active ASINs; calls `GetItems` requesting only pricing resources.
- Compares returned price to current `price_cents` in DB.
- If changed: updates `products.price_cents` and inserts a `price_history` row.
- Also updates `availability` (in_stock / out_of_stock / unknown).

## Acceptance Criteria

- [ ] Only inserts price_history when price actually changes
- [ ] Updates availability field on every run
- [ ] Handles null price from PA-API without overwriting existing DB price
