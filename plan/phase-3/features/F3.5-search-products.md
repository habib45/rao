# F3.5 — search-products Edge Function

## Description

GET endpoint providing full-text search over products using PostgreSQL tsvector columns. Used by the Next.js search page.

## Business Logic

- Query param: `q` (keywords), `locale` (en/bn-BD/sv), `page`, `pageSize`.
- Queries the locale-appropriate `tsvector` column (or falls back to `en`).
- Returns paginated `{ products, total }` with product images joined.
- Minimum query length: 2 characters.

## Acceptance Criteria

- [ ] Returns products matching tsvector query for given locale
- [ ] Returns empty array (not error) for no matches
- [ ] Returns 400 if q is missing or < 2 chars
- [ ] Pagination works correctly (page × pageSize offset)
