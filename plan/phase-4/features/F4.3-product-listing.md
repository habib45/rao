# F4.3 — Product Listing Page

## Description

Paginated product grid at `/[locale]/products` with sidebar filters. Filters are URL search params (no client state), enabling ISR-compatible filtering.

## Filters (URL params)

- `category` — category slug
- `sort` — `price_asc`, `price_desc`, `newest`, `rating`
- `page` — pagination (default: 1)
- `pageSize` — 20

## Layout

- Sidebar (desktop) / bottom sheet (mobile): category filter, sort selector
- Main area: product grid (4-column desktop, 2-column mobile)
- Pagination controls (Previous / Next / page numbers)
- Result count: "Showing 1-20 of 143 products"

## ISR

```ts
export const revalidate = 3600;
```

## Acceptance Criteria

- [ ] URL params drive all filters (sharable URLs)
- [ ] Empty state shown when no products match filters
- [ ] Pagination does not show if total <= pageSize
- [ ] Sort by price works correctly (ascending/descending)
