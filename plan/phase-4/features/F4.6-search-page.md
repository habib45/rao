# F4.6 — Search Page

## Description

Client-rendered search results page at `/[locale]/search?q=keywords`. Calls the `search-products` Edge Function. Results update as the user types (with 300ms debounce).

## Behavior

- Reads `q` from URL search params on initial render
- Shows "No results for '...'" when empty
- Minimum 2 characters before search fires
- Loading spinner during fetch
- Results rendered as `ProductCard` grid

## Acceptance Criteria

- [ ] Search results appear for valid query
- [ ] Empty state shown for no results
- [ ] Does not fetch for q < 2 characters
- [ ] URL updates as user types (pushState)
- [ ] Locale-appropriate tsvector used based on current locale
