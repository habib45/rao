# F4.5 — Category Pages

## Description

Category listing (`/[locale]/categories`) and category detail (`/[locale]/categories/[slug]`). The detail page shows all products in the category with the same filters as the product listing page.

## Category Listing

- Grid of `CategoryCard` components
- Shows top-level categories only (parent_id IS NULL)
- Each card shows product count

## Category Detail

- Category name + description (locale-aware)
- Breadcrumb: Home > Categories > [Category Name]
- Product grid (same component as F4.3, filtered by category_id)
- Sub-categories shown if any exist

## Static Generation

```ts
export async function generateStaticParams() {
  return allCategories.map(c => ({ locale: [...locales], slug: c.slug.en }))
}
export const revalidate = 3600;
```
