# F4.2 — Homepage

## Description

The root locale page (`/[locale]`). Server component with ISR (revalidate: 3600). Displays hero section, featured products grid, and top categories.

## Sections

1. **Hero** — headline text (translated), CTA button → `/[locale]/products`
2. **Featured Products** — grid of up to 8 `ProductCard` where `is_featured = true`
3. **Categories Grid** — top-level categories (parent_id IS NULL) as `CategoryCard` grid
4. **Recently Added** — latest 4 active products by `created_at`

## SEO

- `generateMetadata` returns title, description, OG image, hreflang alternates
- No noindex — homepage is fully indexable

## ISR

```ts
export const revalidate = 3600;
```

## Acceptance Criteria

- [ ] Renders in all 3 locales without errors
- [ ] Featured products section hidden if no featured products
- [ ] generateMetadata returns correct hreflang for all 3 locales
- [ ] Page builds statically (`next build` generates static HTML)
