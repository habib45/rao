# F4.4 — Product Detail Page

## Description

Individual product page at `/[locale]/products/[slug]`. ISR with JSON-LD structured data. The affiliate redirect happens client-side: "View Deal" calls track-click Edge Function then opens the Amazon URL.

## Sections

1. **Image gallery** — primary image large + thumbnail strip
2. **Product info** — name, brand, rating, review count, price, availability badge
3. **Description** — full locale-aware description
4. **Features** — bulleted list
5. **"View on Amazon" CTA** — calls track-click, then navigates to Amazon affiliate URL
6. **"Add to Cart"** — AddToCartButton
7. **Price History** — small sparkline (optional, uses price_history table)
