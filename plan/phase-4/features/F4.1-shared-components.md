# F4.1 — Shared UI Components

## Components

### Header
- Logo + site name (links to `/{locale}`)
- Navigation links: Home, Products, Categories
- `SearchBar` embedded in header
- LocaleSwitcher (en | বাংলা | Svenska) — preserves current path
- Cart icon with item count badge (reads from CartProvider)

### Footer
- Copyright, affiliate disclosure text
- Links: Privacy Policy, Terms, Contact
- Locale-aware (uses next-intl `useTranslations`)

### ProductCard
- `next/image` thumbnail (primary image)
- Product name (locale-aware from `TranslationMap`)
- Price display (formatted via `Intl.NumberFormat`)
- Rating stars + review count
- "View Deal" button → affiliate redirect link
- Availability badge (in stock / out of stock)
- "Add to Cart" button (`AddToCartButton`)

### ProductCardSkeleton
- Matching layout to `ProductCard` with gray animated placeholder blocks
- Used in Suspense fallbacks

### CategoryCard
- Category image + name
- Links to `/[locale]/categories/[slug]`

### SearchBar
- Debounced (300ms) controlled input
- On submit → navigates to `/[locale]/search?q=...`
- Clears on locale change

### AddToCartButton
- Client component ("use client")
- Reads `useCart()` context
- Shows "Added!" confirmation for 2s after click

## Acceptance Criteria

- [ ] ProductCard renders with missing image gracefully (placeholder)
- [ ] ProductCard shows "Out of Stock" badge when availability !== in_stock
- [ ] LocaleSwitcher preserves path across locale changes
- [ ] SearchBar debounces at 300ms before navigating
- [ ] All components are accessible (ARIA labels, keyboard nav)
