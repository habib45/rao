# F4.7 — Data Query Helpers

## Description

Server-side Supabase query functions used by all page server components. These are typed, reusable, and cache-friendly (used with ISR revalidation).

## `src/lib/queries/products.ts`

```ts
getProducts(opts: { locale, categoryId?, sort?, page, pageSize }): Promise<{ products: Product[], total: number }>
getProduct(slug: string, locale: LocaleCode): Promise<Product | null>
getFeaturedProducts(locale: LocaleCode): Promise<Product[]>
getRecentProducts(locale: LocaleCode, limit: number): Promise<Product[]>
getAllProductSlugs(): Promise<{ locale: LocaleCode, slug: string }[]>
```

## `src/lib/queries/categories.ts`

```ts
getCategories(locale: LocaleCode): Promise<Category[]>
getCategory(slug: string, locale: LocaleCode): Promise<Category | null>
getAllCategorySlugs(): Promise<{ locale: LocaleCode, slug: string }[]>
```

## Acceptance Criteria

- [ ] `getProduct` returns null for unknown slug (not throws)
- [ ] `getProducts` respects sort parameter correctly
- [ ] All functions use Supabase server client (cookies)
- [ ] Return types match domain types from `src/types/domain.ts`
