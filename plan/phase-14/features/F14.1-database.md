# F14.1 — Blog Database Schema

Migration: `supabase/migrations/00011_blog_system.sql`

## Tables

### `blog_categories`
- `id` UUID PK (gen_random_uuid)
- `name`, `slug`, `description` JSONB (TranslationMap)
- `sort_order` INT default 0
- `is_active` BOOL default true
- `created_at`, `updated_at` TIMESTAMPTZ default now()

### `blog_tags`
- `id`, `name`, `slug` (JSONB), `created_at`

### `blog_posts`
- Translatable JSONB columns: `title`, `slug`, `excerpt`, `meta_title`, `meta_description`
- English-only TEXT: `content` (TipTap HTML), `featured_image_alt`, `author_name`, `author_avatar_url`, `featured_image_url`
- `category_id` FK → blog_categories ON DELETE SET NULL
- `post_status` TEXT CHECK (`draft | published | archived`) default `draft`
- `is_featured`, `is_trending` BOOL default false
- `view_count`, `like_count`, `comment_count` INT default 0
- `publish_at`, `published_at` TIMESTAMPTZ NULL
- `reading_time_minutes` INT default 0
- `search_vector_en` TSVECTOR (English full-text index)

### `blog_post_tags` (junction)
- `post_id`, `tag_id` (PK)

### `blog_post_views`
- `id`, `post_id`, `session_id`, `locale`, `referrer`, `viewed_at`

### `blog_comments`
- `id`, `post_id`, `parent_id`, `author_name`, `author_email`, `content`, `is_approved`, `created_at`

## Indexes

- GIN: `blog_posts(title)`, `blog_posts(slug)`, `blog_posts(search_vector_en)`, `blog_categories(name)`, `blog_categories(slug)`
- B-tree: `category_id`, `post_status`, `is_featured`, `is_trending`
- Composite: `(post_status, published_at DESC)`
- `blog_post_views(post_id, viewed_at)`
- `blog_comments(post_id, is_approved)`

## Triggers

- BEFORE UPDATE on `blog_posts`, `blog_categories` → `set_updated_at()`
- BEFORE INSERT/UPDATE on `blog_posts` → set `search_vector_en` from `title->>'en'`, `excerpt->>'en'`, `content`

## Functions

- `publish_scheduled_blog_posts()` — promotes drafts whose `publish_at <= now()` to published
- `increment_blog_view_count(post_id_param UUID)` — atomic `view_count` bump
