# F1.2 — Domain Types: Test Cases

## Test File: `src/types/__tests__/domain.test.ts`

These are compile-time type tests using `expectTypeOf` from vitest, plus runtime validation tests for type guard utilities.

---

### Unit Tests — Type Correctness

#### TC-1.2.1: LocaleCode is exactly 3 values
```
Test: Assign 'en', 'bn-BD', 'sv' to LocaleCode variable
Assert: All three compile successfully
Test: Assign 'fr' to LocaleCode variable
Assert: TypeScript compile error (via expectTypeOf)
Coverage: LocaleCode union completeness
```

#### TC-1.2.2: TranslationMap accepts partial locales
```
Test: Create TranslationMap with only { en: 'Hello' }
Assert: Compiles without error
Test: Create TranslationMap with { en: 'Hello', 'bn-BD': 'হ্যালো' }
Assert: Compiles without error
Test: Create TranslationMap with {} (empty)
Assert: Compiles without error (Partial<Record<...>>)
Coverage: TranslationMap flexibility
```

#### TC-1.2.3: TranslationMap generic type parameter
```
Test: Create TranslationMap<string[]> with { en: ['Feature 1'] }

Test: Create TranslationMap<number> with { en: 42 }
Assert: Compiles; value type is number
Test: Create TranslationMap<string[]> with { en: 'not an array' }
Assert: TypeScript compile error
Coverage: TranslationMap<T> generic
```
