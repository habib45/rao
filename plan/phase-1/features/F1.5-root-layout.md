# F1.5 — Root Layout & Font Loading

## Description

Create the root locale layout (`src/app/[locale]/layout.tsx`) that sets the HTML lang attribute, conditionally loads Noto Sans Bengali for the bn-BD locale, wraps children in the next-intl provider and CartProvider, and includes the affiliate disclosure footer.

## Business Logic

### Font Strategy
- **Default font (all locales):** Inter via `next/font/google` — clean, modern sans-serif.
- **Bengali font (bn-BD only):** Noto Sans Bengali via `next/font/google` — loaded conditionally to avoid unnecessary font download for en/sv users.
- Bengali text requires `line-height >= 1.7` for readability (conjunct characters need extra vertical space).
- Both fonts use `display: 'swap'` to prevent FOIT (Flash of Invisible Text).

### Layout Responsibilities
1. Set `<html lang={locale} dir="ltr">`
2. Apply Inter font to `<body>` for all locales
3. Conditionally add Noto Sans Bengali class for bn-BD
4. Apply `leading-relaxed` (line-height: 1.7+) class for bn-BD
5. Wrap children in `NextIntlClientProvider` with messages for the current locale
6. Wrap children in `CartProvider` (Phase 5 — stub for now)
7. Render `{children}` (page content)
8. Include affiliate disclosure text in a footer element

### Metadata
- Default metadata in layout:
  - `title.template`: `%s | BestFinds`
  - `title.default`: `BestFinds — Best Products on Amazon`
  - `description`: locale-specific default description
  - `metadataBase`: from `NEXT_PUBLIC_SITE_URL` env var

## UI Behavior

| Locale | Font Stack | Line Height | HTML Lang |
|---|---|---|---|
| en | Inter | 1.5 (default) | `en` |
| bn-BD | Inter + Noto Sans Bengali | 1.7+ | `bn-BD` |
| sv | Inter | 1.5 (default) | `sv` |

### Bengali Font Conditional Loading
```
if locale === 'bn-BD':
  <body className={`${inter.className} ${notoSansBengali.className} leading-[1.75]`}>
else:
  <body className={inter.className}>
```

### Affiliate Disclosure
Every page must display (in the footer or layout):
> "As an Amazon Associate, we earn from qualifying purchases."

This is a legal requirement per Amazon Associates Operating Agreement.

## Edge Cases

| Case | Expected Behavior |
|---|---|
| Invalid locale in URL (e.g., `/fr`) | Middleware handles redirect before layout renders |
| Missing messages file for locale | `notFound()` or fall back to en messages |
| Noto Sans Bengali font CDN failure | `display: 'swap'` shows system fallback; text remains readable |
| Inter font CDN failure | Same swap behavior; system sans-serif fallback |
| NEXT_PUBLIC_SITE_URL not set | `metadataBase` is undefined; OG URLs may be relative (non-fatal) |
| Very long Bengali text | line-height 1.75 prevents vertical clipping; no truncation in layout |
| Layout renders before messages load | next-intl handles this with its provider; no flash of untranslated content |
| Nested layouts (product page has own metadata) | Next.js metadata merging handles title.template |
