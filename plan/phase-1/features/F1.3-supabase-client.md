# F1.3 — Supabase Client Setup

## Description

Create two Supabase client factory functions: one for browser-side usage (client components) and one for server-side usage (server components, route handlers). Both use the anon key — the service role key is never used in the frontend.

## Business Logic

- **Browser client** (`createBrowserClient`): Uses `@supabase/ssr`'s `createBrowserClient` to create a Supabase client that works in React client components. Reads env vars `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
- **Server client** (`createServerClient`): Uses `@supabase/ssr`'s `createServerClient` with Next.js `cookies()` for cookie-based auth. Used in server components, server actions, and route handlers.
- Both clients use the anon key. RLS policies enforce access control.
- The service role key (`SUPABASE_SERVICE_ROLE_KEY`) is ONLY used in Supabase Edge Functions, never in the Next.js app.

## Files

### lib/supabase/client.ts
```typescript
// Browser client — use in 'use client' components
import { createBrowserClient as createClient } from '@supabase/ssr';

export function createBrowserClient() {
  return createClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
  );
}
```

### lib/supabase/server.ts
```typescript
// Server client — use in server components, route handlers, server actions
import { createServerClient as createClient } from '@supabase/ssr';
import { cookies } from 'next/headers';

export async function createServerClient() {
  const cookieStore = await cookies();

  return createClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return cookieStore.getAll();
        },
        setAll(cookiesToSet) {
          try {
            cookiesToSet.forEach(({ name, value, options }) =>
              cookieStore.set(name, value, options)
            );
          } catch {
            // Called from a Server Component — cookies are read-only.
            // This is expected and can be safely ignored if middleware
            // refreshes the session.
          }
        },
      },
    }
  );
}
```

## API Requirements

| Env Variable | Required | Scope | Description |
|---|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Yes | Client + Server | Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Yes | Client + Server | Supabase anonymous/public key |

Both are `NEXT_PUBLIC_` prefixed because they are safe for client-side use (RLS enforces security).

## UI Behavior

None — these are utility functions consumed by components and pages.

## Edge Cases

| Case | Expected Behavior |
|---|---|
| Missing NEXT_PUBLIC_SUPABASE_URL | Runtime error on first client creation; documented in .env.example |
| Missing NEXT_PUBLIC_SUPABASE_ANON_KEY | Runtime error on first client creation; documented in .env.example |
| Server client called in client component | Import error — `cookies()` is server-only; TypeScript/bundler catches this |
| Browser client called during SSR | `createBrowserClient` handles SSR gracefully (no window reference) |
| Cookie write in Server Component | Silently caught; middleware handles session refresh |
| Invalid Supabase URL format | Supabase SDK throws; should be caught by integration tests |
| Network error (Supabase unreachable) | SDK returns error objects; consuming code must handle `.error` field |
| Multiple concurrent createServerClient calls | Each gets fresh cookie state; no shared mutable state |

## Acceptance Criteria

- [ ] `createBrowserClient()` returns a Supabase client instance
- [ ] `createServerClient()` returns a Supabase client instance with cookie integration
- [ ] Neither function imports or uses `SUPABASE_SERVICE_ROLE_KEY`
- [ ] Both functions use `NEXT_PUBLIC_` prefixed env vars only
- [ ] Server client handles cookie write errors gracefully (try/catch)
- [ ] Browser client is importable from `@/lib/supabase/client`
- [ ] Server client is importable from `@/lib/supabase/server`
- [ ] Type safety: clients return typed Supabase client objects
