# F13.4 — Product Form Integration

## Goal
Replace plain image URL inputs in `ProductCreateForm` and `ProductEditForm` with a "Browse Media" flow powered by the Phase 13 media manager.

## UX
Each image URL row becomes:

```
┌──────────────────────────────────────────────────────┐
│  [ https://… image url ]  [ Browse Media ] [ − ]    │
└──────────────────────────────────────────────────────┘
```

Clicking **Browse Media** opens the `MediaPickerDialog` (a reusable client component). Selecting a file and confirming writes the full public URL back into the input.

## Contract

```tsx
// Reused by both forms.
<MediaPickerDialog
  open={mediaOpen}
  onClose={(url) => {
    if (url) updateImageUrl(index, url);
    setMediaOpen(false);
  }}
/>
```

Dialog internals:
- Left pane: `FolderTree` (navigates within `media` bucket).
- Right pane: `FileGrid` in selection mode (single-select).
- Footer: "Cancel" and "Choose" buttons.

## Changes
- `ProductCreateForm.tsx`: add a `Browse Media` button per image URL row, state `mediaDialogIndex: number | null`, handler that updates the selected row.
- `ProductEditForm.tsx`: same pattern.
- Upload-from-dialog: the picker dialog also exposes the `UploadDropzone`, so admins can upload a new image without leaving the product form.

## No Breaking Changes
- Existing manual URL input still works — operators who already have a CDN URL can paste it directly.
- When the chosen URL is a Supabase public URL, the rest of the pipeline (`next/image`, storefront) works without further changes because the bucket is public.
