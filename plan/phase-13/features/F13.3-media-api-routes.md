# F13.3 — Media API Routes

All routes require admin and use the service-role client.

## `GET /admin/api/media?path=<folder>`
`src/app/admin/api/media/route.ts`

- Lists files + folders at `path` (default `""`).
- Calls `supabase.storage.from('media').list(path, { limit: 200, sortBy: { column: 'name', order: 'asc' } })`.
- Filters out `.keep` placeholder objects from the returned file list (but keeps them as folder markers).
- Returns `{ folders: string[], files: FileEntry[] }` where
  ```ts
  interface FileEntry {
    name: string;
    path: string;        // full path including `path` prefix
    size: number | null;
    mimeType: string | null;
    publicUrl: string;   // `${NEXT_PUBLIC_SUPABASE_URL}/storage/v1/object/public/media/${path}`
    updatedAt: string;
  }
  ```

## `POST /admin/api/media`
Same file as above.

- Body: `{ path: string; folderName: string }`.
- Zod-validated (`folderName` `^[a-zA-Z0-9_-]+$`, 1–64 chars).
- Uploads a zero-byte `Blob` to `<path>/<folderName>/.keep`.
- Returns `{ path: "<path>/<folderName>" }`.

## `POST /admin/api/media/upload`
`src/app/admin/api/media/upload/route.ts`

- Reads `FormData` from the request (`req.formData()`).
- Fields: `file: File`, `path: string`.
- Validates MIME type is image/*.
- Writes to `${path}/${file.name}` using `supabase.storage.from('media').upload(key, file, { contentType, upsert: false })`.
- Returns `{ file: FileEntry }`.

## `DELETE /admin/api/media/[...path]`
`src/app/admin/api/media/[...path]/route.ts`

- `params` yields `{ path: string[] }`; joined path = `path.join('/')`.
- If the path refers to a folder (no file extension matches image types), list all children and delete them + the `.keep` marker.
- Otherwise delete the single file.
- Returns `{ deleted: number }`.

## Validation Rules
- `path` must never start with `/` and must not contain `..` segments (sanitised with a simple regex).
- File size limit: 5 MB per upload (enforced server-side with `file.size > 5 * 1024 * 1024` → 413).

## Error Handling
- Supabase storage errors bubble up as 500 JSON responses with `{ error: msg }`.
- Unauthorized requests (no admin claim) short-circuit via `requireAdmin()` and return 401/403 upstream.

## Edge Cases
- Duplicate filename: returns 409 unless `?overwrite=1` is passed (not exposed in v1 UI).
- Empty folder deletion: still removes the `.keep` marker.
- Path traversal: stripped before any storage call.
