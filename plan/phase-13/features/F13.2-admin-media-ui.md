# F13.2 — Admin Media Manager UI

## Page: `src/app/admin/media/page.tsx`

Server component that requires admin and renders a two-pane layout via `AdminShell`:

```
┌──────────── AdminShell ───────────────────────────────┐
│ ┌── FolderTree ───┐ ┌─── FileGrid ───────────────────┐│
│ │ / (root)        │ │ [+ Upload]  [+ Folder]         ││
│ │ └─ products     │ │ ┌──┬──┬──┬──┬──┐               ││
│ │   └─ 2026       │ │ │  │  │  │  │  │               ││
│ │ └─ banners      │ │ └──┴──┴──┴──┴──┘               ││
│ │                 │ │                                ││
│ └─────────────────┘ └────────────────────────────────┘│
└───────────────────────────────────────────────────────┘
```

## Client Components

### `FolderTree` (client)
- Fetches folder structure lazily per path (only children).
- State: current path string, expanded set.
- "+ New Folder" button opens `CreateFolderDialog`.
- Click a folder → `router.replace(?path=...)` and re-fetch grid.

### `FileGrid` (client)
- Fetches `GET /admin/api/media?path=<current>`.
- Renders:
  - Drag-and-drop zone (visible when drag is active).
  - Responsive grid (`grid-cols-2 md:grid-cols-4 lg:grid-cols-6`).
  - Card per file: `next/image` with explicit width/height (thumb size 160×160), filename (truncated), size (KB), "Copy URL", "Delete" buttons.
- Filter to images only by MIME type.

### `UploadDropzone` (client)
- Drag-and-drop files + `<input type="file" multiple accept="image/*">` picker.
- POSTs each file to `/admin/api/media/upload` with `FormData`: fields `file`, `path`.
- Shows per-file progress via `XMLHttpRequest` (fetch doesn't expose progress).
- On success, refetches the current grid.

### `CreateFolderDialog` (client)
- Input: folder name (alphanumeric + `-` + `_` only, validated client-side).
- POSTs to `/admin/api/media` with `{ path, folderName }`.
- Closes and refreshes on success.

### `MediaPickerDialog` (client, embeddable)
- Reuses `FolderTree` + `FileGrid` inside a modal.
- Props: `open`, `onClose(url: string | null)`.
- Clicking a file selects it (visual ring) and enables "Choose"; "Choose" closes with the public URL.
- Used by Phase 13.4 product form integration.

## Styling
- Uses existing admin CSS vars (`--color-brand`, `--color-surface`, etc.).
- Follows the same card / table patterns as the rest of the admin panel.
- Dark mode adapts via `.dark` class on `<html>`.

## Accessibility
- Drop zone has `aria-label="Upload images"`.
- Every icon button has an `aria-label`.
- Dialogs trap focus (handled by existing `Dialog` primitive).
