# F17.4 — Sitemap API Routes

## Goal

Implement all server-side API routes for sitemap management. All routes call `requireAdmin()` first.

---

## Route: `GET|POST|PATCH|DELETE /admin/api/sitemap/route.ts`

### GET — list or preview

Query params:
- `action=custom` → returns paginated `sitemap_custom_entries`
- `action=preview` → runs the same logic as `sitemap.ts` and returns the entry array as JSON (no XML)

```
GET /admin/api/sitemap?action=custom&page=1&limit=50
→ { entries: SitemapCustomEntry[], total: number }

GET /admin/api/sitemap?action=preview&page=1&limit=50
→ { entries: SitemapPreviewEntry[], total: number }
```

### POST — create custom entry

Body validated by `sitemapCustomEntrySchema`:
```typescript
z.object({
  url: z.string().url().refine(url => url.startsWith(SITE_URL)),
  priority: z.number().min(0.1).max(1.0),
  changefreq: z.enum(['always','hourly','daily','weekly','monthly','yearly','never']),
  last_modified: z.string().datetime().optional().nullable(),
  is_active: z.boolean().default(true),
  notes: z.string().max(500).optional(),
})
```

Returns `201` with created row.

### PATCH — update custom entry

Query param: `?id={uuid}`  
Body: `sitemapCustomEntrySchema.partial()`  
Returns `200` with updated row.

### DELETE — delete custom entry

Query param: `?id={uuid}`  
Hard delete (not soft, since these are admin-managed not user data).  
Returns `204`.

## Route: `GET|PATCH /admin/api/sitemap/exclusions/route.ts`

### GET
```
→ { slugs: string[] }
```
Reads `admin_settings` where `key = 'sitemap_exclusions'`.

### PATCH — add or remove a slug

Body:
```typescript
z.object({
  add: z.string().min(1).optional(),
  remove: z.string().min(1).optional(),
}).refine(data => data.add ?? data.remove, "Provide add or remove")
```

Reads current slugs array, applies the change, writes back.  
Returns `200` with updated `{ slugs: string[] }`.

---

## Route: `POST /admin/api/sitemap/revalidate/route.ts`

```typescript
import { revalidatePath } from "next/cache";

export async function POST(req: Request) {
  await requireAdmin(req);
  revalidatePath("/sitemap.xml", "page");
  return Response.json({ revalidated: true });
}
```

Returns `200 { revalidated: true }`.

---

## Route: `GET|PATCH /admin/api/sitemap/robots/route.ts`

### GET
Reads `admin_settings` where `key = 'robots_config'`.  
```
→ { rules: RobotsRule[] }
```

### PATCH

Body:
```typescript
z.object({
  rules: z.array(z.object({
    userAgent: z.string().min(1),
    allow: z.array(z.string()),
    disallow: z.array(z.string()),
  })).min(1),
})
```

Writes to `admin_settings.robots_config`.  
Returns `200` with updated rules.

## Acceptance Criteria

- [ ] All 4 routes call `requireAdmin()` — 401 returned without valid admin JWT
- [ ] POST custom entry validates URL must start with site URL (400 on violation)
- [ ] PATCH exclusions correctly mutates the slugs array in `admin_settings`
- [ ] Revalidate route calls `revalidatePath` and returns 200
- [ ] Robots PATCH stores valid structured rules
- [ ] All routes return proper error shapes: `{ error: string, issues?: ... }`
