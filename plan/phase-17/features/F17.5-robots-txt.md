# F17.5 — Dynamic Robots.txt

## Goal

Make `robots.ts` read its rules from `admin_settings` so admins can update crawl directives without touching code or redeploying.

---

## Current State

`src/app/robots.ts` returns a hardcoded object:
```typescript
{
  rules: [{ userAgent: "*", allow: "/", disallow: ["/api/", "/_next/"] }],
  sitemap: `${BASE_URL}/sitemap.xml`,
}
```

---

## Proposed Change

```typescript
// src/app/robots.ts
import type { MetadataRoute } from "next";
import { createServerClient } from "@/lib/supabase/server";

export const revalidate = 3600;

const BASE_URL = process.env.NEXT_PUBLIC_SITE_URL ?? "https://bestfinds.com";

type RobotsRule = { userAgent: string; allow: string[]; disallow: string[] };

export default async function robots(): Promise<MetadataRoute.Robots> {
  const supabase = await createServerClient();
  const { data } = await supabase
    .from("admin_settings")
    .select("value")
    .eq("key", "robots_config")
    .single();

  const rules: RobotsRule[] = data?.value?.rules ?? defaultRules;

  return {
    rules: rules.map(r => ({
      userAgent: r.userAgent,
      allow: r.allow,
      disallow: r.disallow,
    })),
    sitemap: `${BASE_URL}/sitemap.xml`,
  };
}

const defaultRules: RobotsRule[] = [
  { userAgent: "*", allow: ["/"], disallow: ["/api/", "/_next/", "/admin/"] },
];
```

Key points:
- Falls back to `defaultRules` if DB read fails (resilient)
- `revalidate = 3600` — cached for 1 hour, same as sitemap
- The sitemap URL is always injected from env, not user-editable (prevents accidental breakage)

---

## SEO Best Practices Enforced

| Rule | Enforcement |
|---|---|
| `/admin/` disallowed | Included in default `defaultRules`; also in seeded `robots_config` |
| `/_next/` disallowed | Same |
| Sitemap URL always present | Hardcoded in `robots()` return, not editable |
| No crawl delay on `*` | Not added by default (Google ignores it; Bing honours but we skip for now) |
