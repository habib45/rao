# F17.2 — Modify `sitemap.ts` to Read DB Overrides

## Goal

Update the dynamic Next.js sitemap route to:
1. Incorporate `sitemap_custom_entries` from DB
2. Exclude slugs listed in `admin_settings.sitemap_exclusions`
3. Add `export const revalidate` driven by `admin_settings.sitemap_cache_ttl` (default 3600)

---

## No Redeploy Required

`sitemap.ts` is a Next.js App Router special route file. With `revalidate = 3600` it is ISR-cached for 1 hour and regenerated on the next request after expiry. The "Force Regenerate" admin button calls `revalidatePath('/sitemap.xml', 'page')` via a server action, immediately busting the cache.

---

## Changes to `src/app/sitemap.ts`

### New query logic (pseudocode)

```typescript
// 1. Read sitemap_cache_ttl from admin_settings → used as dynamic revalidate
export const revalidate = 3600; // static fallback; real value set from DB

// 2. Fetch exclusions from admin_settings.sitemap_exclusions
const { data: exclusionsSetting } = await supabase
  .from("admin_settings")
  .select("value")
  .eq("key", "sitemap_exclusions")
  .single();
const excludedSlugs: string[] = exclusionsSetting?.value?.slugs ?? [];

// 3. Filter products/categories/posts where slug.en NOT IN excludedSlugs

// 4. Fetch active custom entries
const { data: customEntries } = await supabase
  .from("sitemap_custom_entries")
  .select("url, priority, changefreq, last_modified")
  .eq("is_active", true);

// 5. Append custom entries to the entries array
for (const entry of customEntries ?? []) {
  entries.push({
    url: entry.url,
    lastModified: entry.last_modified ? new Date(entry.last_modified) : new Date(),
    changeFrequency: entry.changefreq as MetadataRoute.Sitemap[number]["changeFrequency"],
    priority: Number(entry.priority),
  });
}
```
