# F17.3 — Admin Sitemap Management Page

## Goal

Build the admin sitemap page with four panels accessible via tabs:
1. **Preview** — paginated read-only table of all generated sitemap entries
2. **Custom URLs** — CRUD for manual `sitemap_custom_entries` rows
3. **Exclusions** — add/remove slugs from the exclusion list
4. **Robots.txt** — edit allow/disallow rules stored in `admin_settings`

---

## Page Structure

### `src/app/admin/sitemap/page.tsx` (server component)
- Calls `requireAdmin()`
- Pre-fetches custom entries count and exclusions list via `getSitemapStats()`
- Renders `<SitemapTabs />` (client component) as the shell
- Title: "Sitemap & Robots"

### `SitemapTabs.tsx` (client, `"use client"`)
- Uses a local `tab` state (`"preview" | "custom" | "exclusions" | "robots"`)
- Renders `<RegenerateButton />` in the top-right corner on all tabs
- Renders the active panel below

---

## Panel: Preview (`SitemapPreviewTable.tsx`)

- **Server-rendered** via `useQuery` (TanStack) hitting `/admin/api/sitemap?action=preview`
- API returns the same entry list that `sitemap.ts` would generate (reads DB same way)
- Table columns: URL | Type (product/category/blog/custom/static) | Last Modified | Priority
- Pagination: 50 rows per page, client-side
- Search/filter: URL text filter, Type filter
- "Open Sitemap" button → opens `/sitemap.xml` in a new tab

---

## Panel: Custom URLs (`CustomEntriesPanel.tsx`)

### List view
- TanStack Query fetches `GET /admin/api/sitemap?action=custom`
- Table: URL | Priority | Changefreq | Last Modified | Active | Actions (Edit, Delete)
- "Add Custom URL" button opens inline form / modal

### Add/Edit form fields
| Field | Type | Validation |
|---|---|---|
| url | text | required, starts with NEXT_PUBLIC_SITE_URL |
| priority | number select (0.1–1.0, step 0.1) | required |
| changefreq | select | one of 7 values |
| last_modified | date (optional) | ISO date |
| is_active | checkbox | default true |
| notes | textarea (optional) | max 500 chars |

- POST `/admin/api/sitemap` to create
- PATCH `/admin/api/sitemap?id={id}` to edit
- DELETE `/admin/api/sitemap?id={id}` to delete

---

## Panel: Exclusions (`ExclusionsPanel.tsx`)

- Fetches `GET /admin/api/sitemap/exclusions` → `{ slugs: string[] }`
- Displays slugs as a list of removable chips
- "Add Exclusion" form: text input for slug (e.g. `old-product-slug`), Add button
- Calls `PATCH /admin/api/sitemap/exclusions` with `{ add: "slug" }` or `{ remove: "slug" }`
- Note displayed: "Enter the `en` slug value. Excludes matching products, categories, and blog posts."

---

## Panel: Robots.txt (`RobotsEditor.tsx`)

- Fetches `GET /admin/api/sitemap/robots` → `{ rules: RobotsRule[] }`
- Displays a simple text editor showing the rendered robots.txt (readonly preview)
- Structured form below for editing:
  - User-agent selector (add new agent or `*`)
  - Allow paths list (add/remove)
  - Disallow paths list (add/remove)
- "Save Rules" → PATCH `/admin/api/sitemap/robots`
- "Preview robots.txt" → opens `/robots.txt` in new tab

---

## `RegenerateButton.tsx` (client)

- "Force Regenerate Sitemap" button with spinner
- Calls `POST /admin/api/sitemap/revalidate`
- On success: shows "Sitemap cache cleared. Changes will appear on next visit." via `sonner` toast
- On error: shows error toast

## Acceptance Criteria

- [ ] Sitemap page accessible at `/admin/sitemap`
- [ ] Nav item "Sitemap" appears in AdminShell sidebar (Map icon)
- [ ] Preview tab loads current sitemap entries without requiring redeploy
- [ ] Custom URL CRUD works: add, edit, toggle active, delete
- [ ] Adding/removing a custom URL is reflected in preview after next fetch
- [ ] Exclusion add/remove correctly updates `admin_settings.sitemap_exclusions`
- [ ] Robots editor saves valid rules and preview matches `/robots.txt`
- [ ] RegenerateButton shows success toast and calls revalidatePath
