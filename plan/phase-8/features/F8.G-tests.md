## Key Testing Patterns Used

### Thenable Supabase Stub
```ts
function makeSupabaseStub(overrides) {
  const chain = { data: ..., error: ... };
  const stub = {
    from: vi.fn().mockReturnThis(),
    select: vi.fn().mockReturnThis(),
    // ... all builder methods
    single: vi.fn().mockResolvedValue(chain),
    then(resolve, reject) {  // Make stub awaitable
      return Promise.resolve(chain).then(resolve, reject);
    },
  };
  return stub;
}
```

### `vi.hoisted()` for Mock Variables
```ts
const { mockGetUser } = vi.hoisted(() => {
  const mockGetUser = vi.fn();
  return { mockGetUser };
});
vi.mock("@supabase/ssr", () => ({ createServerClient: () => ({ auth: { getUser: mockGetUser } }) }));
```

### `server-only` Vitest Alias
```ts
// vitest.config.ts
resolve: {
  alias: { "server-only": path.resolve(__dirname, "./src/test/server-only.ts") }
}
```

### Partial `next/server` Mock (for middleware tests)
```ts
vi.mock("next/server", async () => {
  const actual = await vi.importActual("next/server");
  return {
    ...actual,
    NextResponse: {
      ...actual.NextResponse,
      next: vi.fn(() => new actual.NextResponse(null, { status: 200 })),
    },
  };
});
```
