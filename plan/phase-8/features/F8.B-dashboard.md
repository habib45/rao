# F8.B — Admin Dashboard

## Description

The main landing page at `/admin`. Server component calling `requireAdmin()`. Displays platform health metrics and recent activity.

## Sections

### Stats Cards Row (4 cards)
| Stat | Source |
|---|---|
| Total Products | `COUNT(*) FROM products WHERE is_active=true` |
| Active Categories | `COUNT(*) FROM categories WHERE is_active=true` |
| Clicks (7 days) | `admin_click_trends(7)` sum |
| Clicks (30 days) | `admin_click_trends(30)` sum |

### Click Trends AreaChart (recharts)
- 30-day click volume per day
- X-axis: date labels, Y-axis: click count
- Data from `admin_click_trends(30)` Postgres RPC

### Top Categories BarChart (recharts)
- Horizontal bar chart of top 8 categories by click count
- Data from `admin_top_categories(8)` Postgres RPC

### Top Products List
- Table of 5 most-clicked products
- Columns: thumbnail, name, ASIN, click count, last synced

### Sync Logs Table
- Last 10 sync_logs entries
- Columns: function name, status badge, items processed, started_at, duration

## Query Helpers (`src/app/admin/_lib/queries/dashboard.ts`)

```ts
getDashboardStats(): Promise<DashboardStats>
getClickTrends(days: number): Promise<ClickTrend[]>
getTopCategories(limit: number): Promise<TopCategory[]>
getRecentSyncLogs(limit: number): Promise<SyncLog[]>
getTopProducts(limit: number): Promise<TopProduct[]>
```

## Acceptance Criteria

- [ ] All 4 stats cards render with correct numbers
- [ ] Click trends chart renders with data
- [ ] Empty sync logs shows "No sync activity yet"
- [ ] Dashboard loads without errors when tables are empty
