# F8.C — Products CRUD

## Products List Page (`/admin/products`)

- TanStack Query fetches `/admin/api/products` with pagination (20/page)
- Debounced (300ms) search input
- Category filter select, status filter (all/active/inactive)
- Table columns: thumbnail, name+brand, ASIN, price, rating, status toggle, edit button
- Status toggle calls PATCH immediately (optimistic)

## Product Edit Page (`/admin/products/[id]`)

Tabbed form:

| Tab | Fields |
|---|---|
| General | Brand, Category, Availability, Active toggle, Featured toggle |
| Locales | Name, Slug, Description, Meta Title, Meta Description for each of en/bn-BD/sv |
| Features | Ordered list of feature bullet strings (add/remove) |
| Pricing | price_cents, original_price_cents, discount_pct (0-100), currency |
| Images | Read-only grid of synced Amazon images with Primary badge |

## Force Sync

- `ForceSyncButton` calls POST `/admin/api/products/[id]/sync`
- Triggers the `sync-amazon-products` Edge Function for a single ASIN
- Shows loading spinner during call; toast on success/error

## API Routes

### `GET /admin/api/products`
Params: `page`, `pageSize`, `search`, `category`, `status`

### `PATCH /admin/api/products/[id]`
Body validated with `productUpdateSchema` (Zod `.partial()`)

### `DELETE /admin/api/products/[id]`
Soft delete: `UPDATE products SET is_active=false`

### `POST /admin/api/products/[id]/sync`
Calls Edge Function for single ASIN re-sync

## Validation Schema (`_lib/schemas/product.ts`)

```ts
productUpdateSchema = z.object({
  name: translationMapSchema,           // en required
  slug: translationMapSchema,
  description: translationMapSchema,
  meta_title: translationMapSchema.optional(),
  meta_description: translationMapSchema.optional(),
  features: z.array(z.string()).optional(),
  price_cents: z.number().int().nullable(),
  original_price_cents: z.number().int().nullable(),
  currency: z.enum(["USD","BDT","SEK","EUR","GBP"]).default("USD"),
  discount_pct: z.number().int().min(0).max(100),
  category_id: z.string().uuid().nullable(),
  brand: z.string().optional(),
  availability: z.enum(["in_stock","out_of_stock","unknown"]),
  is_featured: z.boolean(),
  is_active: z.boolean(),
})
```
