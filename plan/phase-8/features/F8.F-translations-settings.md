# F8.F — Translations & Settings

## Translations Editor (`/admin/translations`)

Inline editable table for managing all localized text fields in `products` and `categories` tables.

### TranslationsEditor features
- Table rows: one per (entity, field) pair
- Columns: Entity (product/category), English name, Field (name/description/etc.), Locale, Current Value, Edit Input
- Missing translations highlighted with amber border
- "Missing" badge on rows where the locale field is empty
- Namespace filter (products / categories / all)
- Pending edits tracked in local state
- Single "Save All" button → `PATCH /admin/api/translations`

### API Route: `GET /admin/api/translations`
Returns all localizable fields with `_missing` annotations:
```ts
{ rows: TranslationRow[], stats: { total, missing } }
```

### API Route: `PATCH /admin/api/translations`
Body: `{ updates: TranslationUpdate[] }`
```ts
type TranslationUpdate = {
  table: "products" | "categories";
  id: string;           // UUID
  field: string;        // "name" | "description" | etc.
  locale: "en" | "bn-BD" | "sv";
  value: string;
}
```
Logic: reads current JSONB → merges locale key → writes back with UPDATE

## Settings Page (`/admin/settings`)

### SettingsForm sections

**Affiliate Tags** (per locale)
- en affiliate tag (Amazon Associates tag for en audience)
- bn-BD affiliate tag
- sv affiliate tag

**Sync Configuration** (read-only display)
- Sync schedule: "Sundays 3 AM UTC"
- Price update schedule: "Daily 1 AM UTC"
- Last sync: from most recent sync_logs entry

**Feature Flags** (checkboxes)
- Enable Cart (`features.cart`)
- Enable Reviews (`features.reviews`)
- Enable Price Alerts (`features.priceAlerts`)

### API Route: `GET /admin/api/settings`
Reads `admin_settings` table, returns object keyed by `key`

### API Route: `PATCH /admin/api/settings`
Accepts partial settings object, upserts with `ON CONFLICT (key)`
