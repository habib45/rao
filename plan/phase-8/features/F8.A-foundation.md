# F8.A — Foundation (Auth, Middleware, Layout, UI Primitives)

## Auth

Admin auth uses Supabase's existing JWT. No separate user table needed.

Set admin role in Supabase dashboard:
```sql
UPDATE auth.users SET raw_app_meta_data = raw_app_meta_data || '{"role":"admin"}'
WHERE email = 'admin@example.com';
```

### `src/app/admin/_lib/auth.ts`

```ts
getAdminUser(): Promise<User | null>
  // Reads JWT from cookies, returns user if app_metadata.role === "admin"

requireAdmin(): Promise<User>
  // Calls getAdminUser(); redirects to /admin/login if null
```

## Middleware (`src/middleware.ts` — modified)

```
/admin/login      → pass through (no auth check)
/admin/api/*      → pass through (API routes validate via requireAdmin)
/admin/*          → check JWT; redirect to /admin/login if not admin
/*                → delegate to next-intl middleware
```
