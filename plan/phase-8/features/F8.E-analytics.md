# F8.E — Analytics

## Analytics Page (`/admin/analytics`)

Tabbed layout: **Click Analytics** | **Price History**

## Click Analytics Tab

### Filters
- Date range (from/to date inputs)
- Locale filter (all / en / bn-BD / sv)
- Group by (individual events / by day / by locale / by product)

### ClicksTable
- Paginated table (20/page) of click events
- Columns: date, product name, locale, ASIN
- CSV export button → `GET /admin/api/analytics/clicks/export`
  - Opens `window.open(url)` — browser downloads CSV

### API Route: `GET /admin/api/analytics/clicks`
Params: `from`, `to`, `locale`, `groupBy`, `page`, `pageSize`

- `groupBy=day` → calls `admin_click_trends` RPC
- `groupBy=locale` → SQL GROUP BY locale
- `groupBy=product` → SQL GROUP BY product_id
- Default → paginated raw events

### CSV Export: `GET /admin/api/analytics/clicks/export`
- Streams up to 10,000 rows
- `Content-Disposition: attachment; filename="clicks.csv"`
- Columns: timestamp, product_name, asin, locale, ip_hash

## Price History Tab

### PriceHistoryChart
- Product selector (fetches active products list)
- recharts `LineChart` of price over time (up to 365 entries)
- X-axis: date, Y-axis: price in dollars
- Tooltip shows exact price on hover

### API Route: `GET /admin/api/analytics/price-history`
Params: `product_id` (required), `limit` (default 365)
Returns: `{ history: PriceHistoryEntry[] }`

## Acceptance Criteria

- [ ] Click table paginates correctly
- [ ] CSV export downloads file with correct headers
- [ ] Price history chart renders for any active product
- [ ] Empty state shown for product with no price history
