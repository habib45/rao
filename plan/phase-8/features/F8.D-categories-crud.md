# F8.D — Categories CRUD

## Categories List Page (`/admin/categories`)

TanStack Query fetches `/admin/api/categories`. Table columns:
- Name (en locale), Slug (en), Parent, Product Count, Sort Order, Status, Edit/Deactivate actions

## CategoryFormDialog

Modal used for both create and edit:
- Localized fields for all 3 locales: Name, Slug, Description
- Auto-slug generation button (uses `slugify(name.en)`)
- Parent Category select (top-level categories only)
- Image URL input
- Sort Order number input
- Active checkbox

## API Routes

### `GET /admin/api/categories`
Returns all categories with product count (COUNT join)

### `POST /admin/api/categories`
Body validated with `categorySchema`
Returns 201 with created category

### `PATCH /admin/api/categories/[id]`
Body validated with `categorySchema.partial()`

### `DELETE /admin/api/categories/[id]`
Soft delete: `UPDATE categories SET is_active=false`

## Validation Schema (`_lib/schemas/category.ts`)

```ts
categorySchema = z.object({
  name: z.object({ en: z.string().min(1), "bn-BD": z.string().optional(), sv: z.string().optional() }),
  slug: z.object({ en: z.string().min(1), "bn-BD": z.string().optional(), sv: z.string().optional() }),
  description: z.object({ en: z.string(), "bn-BD": z.string().optional(), sv: z.string().optional() }),
  amazon_node_id: z.string().optional(),
  parent_id: z.string().uuid().nullable().default(null),
  sort_order: z.number().int().default(0),
  image_url: z.string().url().nullable().or(z.literal("")).transform(v => v === "" ? null : v).nullable().default(null),
  is_active: z.boolean().default(true),
})
```

Key: `image_url: ""` → transformed to `null`
