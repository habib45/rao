# F19.1 — Wizard Builder (Admin)

## Summary
A collapsible panel rendered below the CKEditor in BlogPostForm. Lets editors build multi-step wizard blocks and inject them into the post content.

## UI Spec
- "📋 Add Wizard" button appears below the Content editor label
- Panel opens inline (not modal), closeable with ✕
- Tab bar shows all steps; active step is highlighted with brand colour
- "Add Step" button appends a new tab
- Per-step controls: title input, move left/right arrows, remove ✕
- Content textarea (HTML input) with monospace font
- Live HTML preview below textarea (dangerouslySetInnerHTML)
- "Insert Wizard into Content" button encodes and appends to editor
- "Cancel" closes without inserting

## Encoding
```ts
btoa(encodeURIComponent(JSON.stringify({ type: "wizard", steps })))
```

## Inserted HTML
```html
<div class="wizard-block" data-wizard="${encoded}" style="...">
  <strong>📋 Wizard:</strong> Step A | Step B
</div>
```
The inner text is a visual placeholder inside CKEditor only — ignored at render time.

## Validation
- At least 1 step with a non-empty title is required to insert
- Empty-title steps are filtered out before encoding
