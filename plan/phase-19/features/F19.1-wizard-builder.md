# F19.1 — Wizard Builder (Admin)

## Summary
A draggable modal rendered over the admin editor. Lets editors build multi-step wizard blocks and inject them into blog post or product description content.

## UI Spec
- "Add Wizard" button appears below the Content editor label in `BlogPostForm`, `ProductEditForm`, and `ProductCreateForm`
- Modal is draggable via a grab-handle header
- Tab bar shows all steps; active step is highlighted with brand colour
- Steps can be reordered by drag-and-drop on the tab pills or via ← → arrow buttons
- "Add Step" button appends a new tab
- Per-step controls: title input, move left/right arrows, remove ✕
- Content area: full CKEditor instance per step (remounts on step switch via `key={step.id}`)
- "Insert Wizard into Content" / "Update Wizard" button in footer encodes and appends/replaces in editor
- "Cancel" closes without inserting

## Style Controls Row

All controls are in a flex-wrap row between the step tabs and the active step editor:

| Control | Type | Description |
|---|---|---|
| Border color | Color picker | Outer box border color (CSS hex, default `#94a3b8`) |
| Border size | Number input 1–10 | Outer box border thickness in px (default `2`) |
| Show box border | Checkbox | Show / hide the outer wrapper border |
| Show panel border | Checkbox | Show / hide internal dividers (tab-bar bottom, footer top) |
| Panel border color | Color picker | Color for internal dividers (visible only when panel border is on, default `#e2e8f0`) |
| Box shadow | Select dropdown | Tailwind shadow class: None / Small / Medium / Medium+ / Large / Extra Large |
| Show Next / Previous footer | Checkbox | Show / hide the prev/next navigation bar |

## Encoding
```ts
btoa(encodeURIComponent(JSON.stringify({
  type: "wizard",
  steps,
  showFooter,
  shadow,
  showBorder,
  showPanelBorder,
  panelBorderColor,
})))
```

## Inserted HTML
```html
<div class="wizard-block" data-wizard="${encoded}" style="border:${size}px dashed ${color};...">
  <strong>Wizard:</strong> Step A | Step B
</div>
```
The inner text is a visual placeholder inside CKEditor only — ignored at render time.

## Edit Flow
- Existing wizards shown as a list below the editor with **Edit** and **Delete** buttons
- Edit opens the builder modal pre-populated with all step data + all style settings
- "Update Wizard" replaces the encoded block in-place using `replaceWizardBlock()` regex helper

## Validation
- At least 1 step with a non-empty title is required to insert
- Empty-title steps are filtered out before encoding
