# F19.2 — Wizard Block (Frontend)

## Summary
A client-side React component rendered on the public blog post page wherever a `wizard-block` div appears in the stored HTML content.

## Rendering Strategy
`page.tsx` (server component) calls `parseContentSegments(post.content)` which splits the HTML string at every `<div class="wizard-block" ...>` marker using a regex. Each segment is either:
- `{ type: "html", content: string }` → rendered with `dangerouslySetInnerHTML`
- `{ type: "wizard", steps: WizardStep[] }` → rendered with `<WizardBlock>`

## WizardBlock UI
- Tab headers row: each step as a button; active = brand bg
- Completed steps (index < activeIdx) show ✓ prefix
- Step content rendered as HTML (article-content class for styling)
- Footer nav: Previous ← | current/total counter | → Next
- Navigation footer hidden when there is only 1 step
- Smooth opacity transition between steps (CSS transition)

## Accessibility
- Tab buttons have `role="tab"` and `aria-selected`
- Content panel has `role="tabpanel"`
- Previous/Next buttons are `<button>` with descriptive aria-labels
