# F19.2 — Wizard Block (Frontend)

## Summary
A client-side React component rendered on the public blog post and product detail page wherever a `wizard-block` div appears in the stored HTML content.

## Rendering Strategy
`page.tsx` (server component) calls `parseContentSegments(content)` which splits the HTML string at every `<div class="wizard-block" ...>` marker using a regex. Each segment is either:
- `{ type: "html", content: string }` → rendered with `dangerouslySetInnerHTML`
- `{ type: "wizard", steps, showFooter, shadow, showBorder, showPanelBorder, panelBorderColor }` → rendered with `<WizardBlock>`

## WizardBlock Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `steps` | `WizardStep[]` | required | Array of `{ id, title, content }` |
| `showFooter` | `boolean` | `true` | Show/hide the Previous / Next navigation bar |
| `shadow` | `string` | `"shadow-sm"` | Tailwind shadow utility class on outer wrapper |
| `showBorder` | `boolean` | `true` | Show/hide `border border-border` on outer wrapper |
| `showPanelBorder` | `boolean` | `true` | Show/hide internal tab-bar and footer dividers |
| `panelBorderColor` | `string` | `"#e2e8f0"` | Inline style color for internal dividers |

## WizardBlock UI
- Outer wrapper: `rounded-xl bg-white` + conditional `border border-border` + Tailwind shadow class
- Tab headers row: each step as a button; active = brand underline + white bg; background uses `bg-surface`
  - Tab bar bottom divider: conditional inline `borderBottom` style
- Completed steps (index < activeIdx) show ✓ prefix
- Step content rendered as HTML (`article-content` class for prose styling)
- Footer nav (when `showFooter && steps.length > 1`): Previous ← | current/total counter | → Next
  - Footer top divider: conditional inline `borderTop` style

## Style Application

```tsx
// Outer wrapper
<div className={`my-6 overflow-hidden rounded-xl bg-white ${shadow} ${showBorder ? "border border-border" : ""}`}>

// Tab bar — inline style for divider
<div role="tablist" className="flex overflow-x-auto bg-surface" style={showPanelBorder ? { borderBottomWidth:1, borderBottomStyle:"solid", borderBottomColor:panelBorderColor } : {}}>

// Footer — inline style for divider
<div className="flex items-center justify-between px-5 py-3" style={showPanelBorder ? { borderTopWidth:1, borderTopStyle:"solid", borderTopColor:panelBorderColor } : {}}>
```

## Backward Compatibility
Old wizards encoded without the new fields parse correctly — the parser defaults all new fields to their documented defaults, so existing published content is unaffected.

## Accessibility
- Tab buttons have `role="tab"` and `aria-selected`
- Content panel has `role="tabpanel"`
- Previous/Next buttons are `<button>` with descriptive `aria-label`
