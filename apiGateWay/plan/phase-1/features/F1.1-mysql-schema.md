# F1.1 — MySQL Schema Conversion

## Summary
Convert all Supabase PostgreSQL migrations (00001–00020) to a single MySQL 8.0 DDL file.

## Status: ✅ Complete

## File
`mysql/schema.sql`

## Key Conversion Decisions

| PostgreSQL | MySQL 8.0 |
|---|---|
| `UUID PRIMARY KEY DEFAULT gen_random_uuid()` | `VARCHAR(36) NOT NULL DEFAULT (UUID())` |
| `JSONB` | `JSON` |
| `TSVECTOR` + `GIN` index | Generated `TEXT` columns + `FULLTEXT` index |
| `TIMESTAMPTZ` | `DATETIME(6)` with `ON UPDATE NOW(6)` |
| `NUMERIC(2,1)` | `DECIMAL(2,1)` |
| `TEXT NOT NULL DEFAULT ''` | `VARCHAR(N) NOT NULL DEFAULT ''` (MySQL TEXT cannot have defaults) |
| `CREATE TYPE ... AS ENUM` | Inline `ENUM(...)` on column |
| `SERIAL` / sequences | `DEFAULT (UUID())` |
| RLS policies | Dropped — enforced at Express route layer |
| PostgreSQL triggers | Replaced by `ON UPDATE NOW(6)` for `updated_at` |
| `JSONB` GIN indexes | MySQL `JSON` has path-based virtual column indexes |
| Supabase `auth.jwt()` checks | Removed — JWT not used in MySQL gateway |

## FULLTEXT Search Strategy
PostgreSQL `tsvector` columns are replaced with MySQL generated stored columns:
```sql
search_name_en TEXT AS (JSON_UNQUOTE(JSON_EXTRACT(name, '$.en'))) STORED,
search_desc_en TEXT AS (JSON_UNQUOTE(JSON_EXTRACT(description, '$.en'))) STORED,
...
CREATE FULLTEXT INDEX ft_products_en ON products (search_name_en, search_desc_en, brand);
```
Query pattern: `MATCH(col) AGAINST(? IN BOOLEAN MODE)` with trailing `*` for prefix matching.
