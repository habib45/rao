# F1.2–F1.13 — Express.js API Gateway

## Summary
Standalone Express.js gateway serving all ORH BestFinds data from MySQL.

## Status: ✅ Complete

## Route Groups

### Public — `/api/categories`
- `GET /` — list active categories ordered by sort_order
- `GET /:id` — single category
- `POST /` — create (name + slug required)
- `PATCH /:id` — partial update (any allowed field)
- `DELETE /:id` — delete

### Public — `/api/products`
- `GET /` — paginated list with filters: `category_id`, `status`, `is_active`, `is_featured`, `search`, `locale`, `limit`, `offset`
- `GET /comparison/list` — products where `show_in_comparison = TRUE`
- `GET /asin/:asin` — lookup by Amazon ASIN
- `GET /:id` — product with aggregated images JSON array
- `POST /` — create (asin, affiliate_url, name, slug required)
- `PATCH /:id` — partial update
- `DELETE /:id` — delete
- `GET /:id/images` — product images ordered by sort_order
- `POST /:id/images` — add image (url required); auto-clears other is_primary if is_primary=true

### Public — `/api/blog`
- `GET /posts` — paginated with status/featured/category/search filters
- `GET /posts/:id` — post + joined tags array
- `POST /posts` — create with optional tag IDs
- `PATCH /posts/:id` — partial update
- `DELETE /posts/:id` — delete
- `GET /posts/:id/comments` — approved comments only
- `POST /posts/:id/comments` — submit (pending approval, is_approved=false)
- `GET /categories` — active blog categories
- `POST /categories` — create
- `GET /tags` / `POST /tags` — tag list and create

### Public — `/api/newsletter`
- `POST /subscribe` — idempotent (resubscribe if was unsubscribed)
- `POST /unsubscribe` — sets is_active=FALSE, records unsubscribed_at
- `GET /subscribers` — admin list with pagination

### Public — `/api/tracking`
- `POST /click` — record click event (product_id + session_id required, locale validated)
- `GET /clicks/:product_id` — raw click history with optional date range
- `GET /summary` — aggregated clicks per product+locale

### Admin (x-api-key required) — `/api/admin`
- `GET /settings` — all settings as `{ key: value }` map
- `GET /settings/:key` / `PUT /settings/:key` — get/upsert single setting
- `GET /dashboard` — counts + top 10 products by 7-day clicks
- `GET /sync-logs` / `POST /sync-logs` — log history and insert
- `GET /translations` / `PUT /translations/:ns/:key` — UI translation management
- `GET /price-history/:product_id` / `POST /price-history` — price snapshots
- `POST /publish-scheduled` — activates products where `publish_at <= NOW()`
- `GET /sitemap-entries` / `POST /sitemap-entries` / `DELETE /sitemap-entries/:id` — custom sitemap URLs

## Security Notes
- Admin routes protected by `requireApiKey` middleware (checks `x-api-key` header vs `process.env.API_SECRET`)
- Public write routes (POST categories, products, etc.) should be moved behind API key in Phase 3
- No SQL injection risk — all queries use `?` parameterized placeholders
